# 10. ニューラルネットと深層学習

## 現場の問い

深層学習は、特徴量を人が設計しきれない画像、音声、テキスト、複雑なセンサデータで強力です。一方で、データ量、計算資源、デバッグ難度、運用コストが増えます。

## 直感

ニューラルネットは、線形変換と非線形変換を重ねて表現を学びます。浅い層は局所的・単純な特徴を、深い層はタスクに近い抽象的特徴を表すことがあります。

CNN は画像の局所構造、RNN は系列、Transformer は系列内の関係を扱う発想から発展しました。

## 最小限の数式

1 層のニューラルネット:

```text
h = activation(Wx + b)
```

多層ではこれを重ねます。

```text
y_hat = f_L(...f_2(f_1(x)))
```

backpropagation は、損失から各パラメータへの影響を逆向きに計算します。

## 実装で見るべきログ・指標

- train / validation loss。
- GPU メモリ、学習時間、推論時間。
- learning rate、batch size、seed。
- checkpoint と再開可否。
- 小データへの overfit テスト。
- データ拡張の影響。

## よくある失敗

- データが少ないのにゼロから深いモデルを学習する。
- 事前学習モデルを使えるのに使わない。
- loss だけ見て、出力サンプルや失敗例を見ない。
- checkpoint、seed、環境を記録しない。
- GPU で動いた notebook をそのまま本番設計と勘違いする。

## 実務メモ

深層学習では、まず事前学習モデルの転移学習を検討します。ゼロから学習するのは、データ量、計算資源、独自ドメイン性、再現性を説明できるときです。

失敗解析は数値だけでなく、画像・テキスト・音声など入力の実例を並べて見ます。データラベルの誤り、曖昧なケース、前処理の破壊は、曲線だけでは見つかりません。

## 演習

1. 深層学習を使うべきケースと使わない方がよいケースを 3 つずつ挙げる。
2. 小データ overfit テストの目的を説明する。
3. 転移学習で freeze / unfreeze を変える判断基準を書く。
