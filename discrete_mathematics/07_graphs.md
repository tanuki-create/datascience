# Part 7　グラフ理論

## 学習目標

- グラフを頂点と辺の集合として定義し、現実の関係をモデル化できる。
- 道、閉路、連結、木、二部グラフ、Euler路、Hamilton路を区別できる。
- BFS、DFS、最短経路、最小全域木、トポロジカルソートの目的と前提を説明できる。
- 小さなグラフを手で計算し、擬似コードとPythonへ変換できる。

## まず直感

グラフは、対象と対象のつながりを表す図です。

駅を頂点、線路を辺にすれば、経路検索になります。

Webページを頂点、リンクを有向辺にすれば、リンク構造になります。

友人関係は無向グラフ、フォロー関係は有向グラフです。

道路の距離や通信遅延を辺に付けると、重み付きグラフになります。

## 正式な定義

無向グラフ `G=(V,E)` は、頂点集合Vと、頂点の組からなる辺集合Eです。

有向グラフでは辺を `u→v` と書き、向きを区別します。

重み付きグラフでは各辺に数値 `w(u,v)` を割り当てます。

頂点vに接続する辺の本数を**次数**と呼びます。

頂点列 `v0,v1,...,vk` で、隣り合う頂点が辺で結ばれているものを歩行と呼びます。

同じ頂点を二度以上通らない歩行を、ここでは**道（path）**と呼びます。

始点と終点が同じ道を**閉路**と呼びます。

任意の二頂点間に道がある無向グラフを**連結**と呼びます。

すべての異なる頂点対を辺で結ぶグラフを完全グラフ、頂点を二つのグループに分け同じグループ内に辺がないグラフを二部グラフと呼びます。

閉路を持たない連結グラフが**木**、木の集合が**森**です。

連結グラフのすべての頂点を含む木を**spanning tree（全域木）**と呼びます。

すべての辺をちょうど一度通る道がEuler路、閉路ならEuler閉路です。

すべての頂点をちょうど一度訪れる道がHamilton路です。

Hamilton路が始点に戻って閉じるものをHamilton閉路と呼びます。

## 最小の具体例

```text
A --- B --- C
      |
      D
```

`deg(A)=1, deg(B)=3, deg(C)=1, deg(D)=1` です。

このグラフは連結で、閉路はありません。

したがって木です。

## 表現方法

隣接リストは、各頂点の隣接先を保存します。

```text
A: [B]
B: [A,C,D]
C: [B]
D: [B]
```

辺が少ない疎グラフでは、隣接リストの空間 `O(|V|+|E|)` が有利です。

隣接行列は、頂点u,vの間に辺があるかを行列のセルで表し、辺の存在を `O(1)` で調べられます。

## BFSとDFS

**BFS**は始点から近い順に探索します。

重みなしグラフで、始点からの最短辺数を求められます。

```text
BFS(s):
    queue に s を入れる
    s を訪問済みにする
    queue が空でない間:
        u を取り出す
        u の未訪問隣接頂点vをすべて訪問し、queueに入れる
```

キューを使い、計算量は隣接リストで `O(|V|+|E|)` です。

**DFS**は一つの道を深く進み、行き止まりで戻ります。

再帰または明示的なスタックで実装できます。

```text
DFS(u):
    u を訪問済みにする
    u の未訪問隣接頂点vについて DFS(v)
```

DFSも `O(|V|+|E|)` ですが、最短距離を保証する順番ではありません。

## 最短経路アルゴリズム

| アルゴリズム | 問題 | 条件 | 計算量の代表例 |
|---|---|---|---|
| BFS | 重みなし単一始点最短路 | 辺の重みが同じ | `O(V+E)` |
| Dijkstra | 非負重みの単一始点最短路 | 負辺なし | ヒープで `O((V+E)log V)` |
| Bellman-Ford | 単一始点最短路 | 負辺可、負閉路検出 | `O(VE)` |
| Floyd-Warshall | 全点対最短路 | 頂点数が比較的小さい | `O(V^3)` |

### Dijkstra法の手計算

```text
A --1-- B --2-- C
 \     5       /
   ----- D ----
```

辺 `A-D=5, D-C=1` とします。

1. Aの距離を0、Bを1、Dを5と置きます。
2. 最小の未確定頂点Bを確定します。
3. BからCを更新し、Cの距離を `1+2=3` とします。
4. 次にCを確定すると、D経由の `5+1=6` より距離3が短いと分かります。

Dijkstra法は、確定した距離が後で短くならないことを、辺の重みが非負であることに依存します。

### Bellman-Ford法

すべての辺を最大 `V-1` 回緩和します。

さらに一回更新できたら、始点から到達可能な負閉路があると判断できます。

### Floyd-Warshall法

中継に使える頂点集合を一つずつ増やし、

```text
d[i][j] = min(d[i][j], d[i][k] + d[k][j])
```

で更新します。

## 最小全域木

全域木のうち、辺の重みの合計が最小のものを最小全域木（MST）と呼びます。

**Kruskal法**は、辺を重みの小さい順に並べ、閉路を作らない辺を加えます。

Union-Findを使うと、同じ連結成分かを効率よく判定できます。

**Prim法**は、すでに選んだ頂点集合から外へ出る最小辺を加えます。

Kruskalは辺の順序、Primは頂点集合の拡張という違いがあります。

## トポロジカルソートと彩色

有向非巡回グラフ（DAG）では、辺 `u→v` の前にuが来るよう頂点を並べられます。

入次数0の頂点を取り出し、辺を削除する方法や、DFSの終了順を使う方法があります。

依存ライブラリのビルド順序が例です。

グラフ彩色は、隣接する頂点に異なる色を割り当てます。

二部グラフであることは、2色で彩色できることと同値です。

## 各アルゴリズムの詳細

ここでは、8つの代表的なアルゴリズムを、目的、数学的背景、考え方、手計算、擬似コード、計算量、利用例の順に整理します。

### 1. BFS（幅優先探索）

#### 目的

始点から、辺の本数が少ない頂点を優先して調べます。

重みなしグラフ、またはすべての辺の重みが同じグラフで、単一始点からの最短辺数を求めることが主な目的です。

#### 数学的背景

始点から距離 `0, 1, 2, ...` の層を順に処理します。

ある頂点uの未訪問隣接頂点vには、最短距離 `dist[v]=dist[u]+1` を設定できます。

距離kの頂点を処理し終えるまで距離k+1の頂点を取り出さないことが、最短性の根拠です。

#### 考え方

キューに始点を入れ、取り出した頂点の未訪問隣接頂点をキューの末尾へ追加します。

頂点をキューへ入れる時点で訪問済みにすると、同じ頂点を何度も追加せずに済みます。

#### 小さな手計算例

```text
辺: A-B, A-C, B-D, C-E, D-F, E-F
```

`A`から開始すると、キューと距離は次のようになります。

```text
取り出し前のキュー  取り出す頂点  新しく確定する距離
[A]                 A             A=0
[B,C]               B             B=1
[C,D]               C             C=1
[D,E]               D             D=2
[E,F]               E             E=2
[F]                 F             F=3
```

したがって、`A`から`F`の最短辺数は3です。

#### 擬似コード

```text
BFS(G, s):
    for v in V:
        visited[v] = false
        distance[v] = ∞
    visited[s] = true
    distance[s] = 0
    queue.push(s)

    while queue is not empty:
        u = queue.pop_front()
        for v in G.adj[u]:
            if not visited[v]:
                visited[v] = true
                distance[v] = distance[u] + 1
                parent[v] = u
                queue.push_back(v)
```

#### 計算量

隣接リストでは各頂点と各辺を高々一度調べるため、時間計算量は `O(|V|+|E|)`、追加領域は `O(|V|)`です。

隣接行列では各頂点の行を走査するため、時間計算量は `O(|V|^2)`です。

#### 利用例

迷路の最短手数、SNSの友人距離、ネットワークのホップ数、二部グラフの2色判定に使います。

### 2. DFS（深さ優先探索）

#### 目的

一つの枝を深くたどり、行き止まりで戻ることで、到達可能性、連結成分、閉路、依存関係を調べます。

#### 数学的背景

DFSが初めて未訪問頂点vへ到達した辺を親辺として残すと、DFS木ができます。

無向グラフでは、探索中に親辺でない訪問済み隣接頂点を見つけると閉路の存在を示します。

#### 考え方

再帰呼び出し、またはスタックを使い、現在の頂点から未訪問の隣接頂点へ進み続けます。

すべての子の処理が終わってから頂点を記録する帰りがけ順は、トポロジカルソートにも使えます。

#### 小さな手計算例

辺の隣接順をアルファベット順にします。

```text
辺: A-B, A-C, B-D, C-E, D-F, E-F
```

`A`からDFSを行うと、`A→B→D→F→E→C`の順に初回訪問します。

`F`からは`E`へ進み、`E`から`C`へ進みます。

`C`の隣接頂点はすでに訪問済みなので、戻りながら探索を終えます。

#### 擬似コード

```text
DFS(u):
    visited[u] = true
    for v in G.adj[u]:
        if not visited[v]:
            parent[v] = u
            DFS(v)
    finish_order.append(u)
```

すべての頂点を訪れるには、未訪問頂点ごとに`DFS(v)`を呼びます。

#### 計算量

隣接リストでは時間計算量 `O(|V|+|E|)`、訪問配列とスタックを含む追加領域 `O(|V|)`です。

#### 利用例

ファイルやDOMの走査、連結成分、閉路検出、トポロジカルソート、バックトラッキングに使います。

最短距離を求める目的なら、重みなしグラフでも距離層を保つBFSを選びます。

### 3. Dijkstra法

#### 目的

始点からすべての頂点への最短距離と、その経路を求めます。

#### 数学的背景

辺の重みがすべて `0以上` なら、暫定距離が最小の未確定頂点uは、その時点で最短距離が確定します。

辺 `(u,v)`について `dist[v]` を `min(dist[v], dist[u]+w(u,v))` に更新する操作を緩和と呼びます。

この確定性は負辺がないことに依存します。

#### 考え方

最小の暫定距離を持つ頂点を優先度付きキューから取り出し、その頂点から出る辺を緩和します。

負辺があると、確定済みの頂点へ後から負辺を通って戻る経路が短くなるため、この貪欲な確定は使えません。

#### 小さな手計算例

```text
A→B=1, A→C=10, A→D=5
B→C=2, D→C=1
```

始点Aの初期値を `A=0, B=∞, C=∞, D=∞` とします。

1. Aを確定し、`B=1, C=10, D=5`とします。
2. 最小のBを確定し、`C=min(10,1+2)=3`とします。
3. 次にCの距離3を確定します。
4. Dの距離5を通るCへの候補は `5+1=6` なので、Cの3より長く棄却します。

最短距離は `A=0, B=1, C=3, D=5`です。

#### 擬似コード

```text
Dijkstra(G, s):
    dist[v] = ∞ for all v
    dist[s] = 0
    heap.push((0, s))

    while heap is not empty:
        (du, u) = heap.pop_min()
        if du != dist[u]:
            continue
        for (v, w) in G.adj[u]:
            if w < 0:
                error "negative edge"
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                parent[v] = u
                heap.push((dist[v], v))
    return dist, parent
```

#### 計算量

二分ヒープと隣接リストでは `O((|V|+|E|)log|V|)`です。

隣接行列と単純な最小探索では `O(|V|^2)`です。

#### 利用例

道路の最短時間、ゲーム内の移動コスト、通信遅延、非負の料金を含む経路検索に使います。

負辺が必要なモデルでは、Bellman-Ford法を検討します。

### 4. Bellman-Ford法

#### 目的

負の辺を含む有向グラフで、始点からの最短距離を求め、到達可能な負閉路も検出します。

#### 数学的背景

負閉路がないなら、最短路は同じ頂点を二度通らない単純路にでき、辺数は高々 `|V|-1`です。

そのため、全辺の緩和を `|V|-1` 回行えば、最短距離が伝播します。

さらにもう一回緩和できる辺があれば、始点から到達可能な負閉路を通って距離を無限に小さくできます。

#### 考え方

全辺を一巡して、既知の距離を隣接頂点へ伝えます。

これを繰り返すことで、1本の辺、2本の辺、という順に最短路の候補を広げます。

#### 小さな手計算例

```text
A→B=4, A→C=5, B→C=-2, C→D=3
```

初期値を `A=0, B=∞, C=∞, D=∞` とします。

辺を `A→B, A→C, B→C, C→D` の順に見ると、1回目で `B=4, C=2, D=5`になります。

頂点数は4なので、最大3回の緩和を行います。

2回目、3回目に値が変わらなければ、到達可能な負閉路はありません。

#### 擬似コード

```text
BellmanFord(G, s):
    dist[v] = ∞ for all v
    dist[s] = 0

    repeat |V|-1 times:
        changed = false
        for (u, v, w) in G.edges:
            if dist[u] != ∞ and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                parent[v] = u
                changed = true
        if not changed:
            break

    for (u, v, w) in G.edges:
        if dist[u] != ∞ and dist[u] + w < dist[v]:
            return "reachable negative cycle"
    return dist, parent
```

#### 計算量

時間計算量は `O(|V||E|)`、距離と親を保存する追加領域は `O(|V|)`です。

#### 利用例

負の利益を含むコスト計算、為替裁定の検出、負閉路の検出に使います。

### 5. Floyd-Warshall法

#### 目的

すべての頂点対の最短距離、つまり全点対最短路を一度に求めます。

#### 数学的背景

中継に使える頂点を `1,...,k` に制限した最短距離を考えます。

頂点kを経由しない場合と、`i→k→j`として経由する場合の短い方を選ぶため、

`D[i][j] = min(D[i][j], D[i][k] + D[k][j])`

という動的計画法の漸化式になります。

#### 考え方

中継頂点kを一つずつ許可し、すべての始点iと終点jの組を更新します。

負辺は扱えますが、`D[v][v]<0`になった頂点vがあれば負閉路が存在します。

#### 小さな手計算例

直接辺だけの初期行列を

```text
      A   B   C
A     0   4  10
B     ∞   0   2
C     1   ∞   0
```

とします。

Bを中継に許すと、`A→C`は `min(10,4+2)=6`になります。

Cを中継に許すと、`B→A`は `min(∞,2+1)=3`になります。

このように、kごとに全てのセルを更新します。

#### 擬似コード

```text
FloydWarshall(D):
    for k in V:
        for i in V:
            for j in V:
                D[i][j] = min(D[i][j], D[i][k] + D[k][j])
    for v in V:
        if D[v][v] < 0:
            return "negative cycle"
    return D
```

#### 計算量

三重ループを使うため時間計算量は `O(|V|^3)`、行列の領域は `O(|V|^2)`です。

#### 利用例

都市間の全距離表、ネットワーク遅延表、頂点数が比較的小さいグラフでの繰り返し距離問い合わせに使います。

### 6. Kruskal法

#### 目的

連結な無向重み付きグラフから、全頂点を最小の重み合計でつなぐ最小全域木を求めます。

#### 数学的背景

閉路を作らない部分集合に対して、異なる連結成分をつなぐ最小辺は最小全域木に採用できるというカット性質を使います。

#### 考え方

辺を重みの昇順に並べ、両端が異なる連結成分に属する辺だけを採用します。

両端が同じ成分なら、その辺を採用すると閉路ができるため棄却します。

#### 小さな手計算例

辺を `AB=1, BC=2, AC=3, CD=4, BD=5` とします。

1. `AB=1`を採用します。
2. `BC=2`を採用します。
3. `AC=3`はA-B-Cの閉路を作るため棄却します。
4. `CD=4`を採用すると全頂点が連結します。

MSTは`AB, BC, CD`で、重み合計は `1+2+4=7`です。

#### 擬似コード

```text
Kruskal(G):
    T = empty set
    make_set(v) for each v in V
    sort E by nondecreasing weight
    for (u, v, w) in E:
        if find(u) != find(v):
            T.add((u, v, w))
            union(u, v)
    return T
```

#### 計算量

辺のソートが支配するため、Union-Findの経路圧縮とランク併合を使うと `O(|E|log|E|)`です。

#### 利用例

通信ケーブル、道路、配管の敷設費を最小化する設計や、距離に基づくクラスタリングの骨格に使います。

### 7. Prim法

#### 目的

連結な無向重み付きグラフから最小全域木を求めます。

#### 数学的背景

現在の木と外側の頂点を分けるカットを考え、そのカットを横切る最小辺を選ぶカット性質を使います。

#### 考え方

任意の開始頂点から始め、現在の木の外へ出る辺のうち最小のものを一つずつ加えます。

Kruskal法が辺を全体の順に調べるのに対し、Prim法は一つの木を頂点集合として広げます。

#### 小さな手計算例

Kruskal法と同じ辺 `AB=1, BC=2, AC=3, CD=4, BD=5` を使い、Aから開始します。

1. 木`{A}`から最小の`AB=1`を採用します。
2. 木`{A,B}`から外へ出る最小の`BC=2`を採用します。
3. 木`{A,B,C}`から外へ出る`CD=4`を採用します。

採用辺は`AB, BC, CD`、合計は7です。

#### 擬似コード

```text
Prim(G, s):
    key[v] = ∞ for all v
    parent[v] = None for all v
    key[s] = 0
    heap.push((0, s))

    while heap is not empty:
        (_, u) = heap.pop_min()
        if u is already in T:
            continue
        add u to T
        for (v, w) in G.adj[u]:
            if v is not in T and w < key[v]:
                key[v] = w
                parent[v] = u
                heap.push((w, v))
    return parent
```

#### 計算量

二分ヒープと隣接リストでは `O(|E|log|V|)`、隣接行列では `O(|V|^2)`です。

#### 利用例

頂点から隣接先を取得しやすいグラフで、ネットワークや電力網の接続費を最小化する設計に使います。

### 8. トポロジカルソート

#### 目的

有向非巡回グラフ（DAG）の頂点を、すべての辺`u→v`についてuがvより前になるように並べます。

#### 数学的背景

DAGには必ず入次数0の頂点が存在します。

もしすべての頂点の入次数が1以上なら、矢印を逆向きにたどっていくと有限頂点の中で頂点を再訪し、有向閉路ができるためです。

#### 考え方

入次数0の頂点を取り出し、そこから出る辺を削除します。

削除によって入次数0になった頂点を次の候補に入れます。

最後まで全頂点を取り出せなければ、有向閉路があります。

#### 小さな手計算例

```text
A→C, B→C, C→D, B→E
```

初期の入次数0はAとBです。

`A`、次に`B`を取り出すとCの入次数が0になります。

その後`C`を取り出し、最後に`D,E`を取り出せます。

一つの順序は `A,B,C,D,E`です。

#### 擬似コード

```text
TopologicalSort(G):
    indegree[v] = 0 for all v
    for u in V:
        for v in G.adj[u]:
            indegree[v] += 1
    queue = all v with indegree[v] == 0
    order = []

    while queue is not empty:
        u = queue.pop_front()
        order.append(u)
        for v in G.adj[u]:
            indegree[v] -= 1
            if indegree[v] == 0:
                queue.push_back(v)

    if len(order) != |V|:
        return "cycle exists"
    return order
```

#### 計算量

隣接リストでは入次数の計算と辺の削除を合わせて時間計算量 `O(|V|+|E|)`、追加領域 `O(|V|)`です。

#### 利用例

科目の履修順、ソフトウェアのビルド順、データパイプライン、タスクの依存関係に使います。

閉路がある依存関係にはトポロジカル順序が存在しないため、循環依存の検出にも使えます。

## EulerとHamiltonの違い

Eulerは辺を一度ずつ使う問題、Hamiltonは頂点を一度ずつ使う問題です。

連結な無向グラフでは、すべての次数が偶数ならEuler閉路が存在します。

奇次数の頂点がちょうど0個または2個なら、Euler路が存在します。

一方、一般のHamilton路やHamilton閉路には、次数だけで決まる同様の簡潔な必要十分条件はありません。

Hamilton路の判定は難しい問題なので、頂点数が小さい場合のバックトラッキングや、問題固有の条件を使います。

見た目が似ていても、数える対象が違います。

## 証明の設計と完全な証明

木の頂点数をn、辺数をmとすると `m=n-1` であることを示します。

### 方法の候補

頂点を一つずつ追加する構成、または頂点数に関する帰納法を使います。

### 完全な証明

頂点が1つの木は辺を持たないので、`m=0=1-1` です。

頂点数nの木から葉を一つ取り除くと、残りは頂点数n-1の木になります。

帰納法の仮定より、残りの辺数は `(n-1)-1=n-2` です。

取り除いた葉は元の木でちょうど一辺に接続していたため、元の辺数は `n-2+1=n-1` です。

したがってすべての木で `m=n-1` です。

## Python例

```python
from collections import deque

def bfs(graph, start):
    distance = {start: 0}
    queue = deque([start])
    while queue:
        u = queue.popleft()
        for v in graph[u]:
            if v not in distance:
                distance[v] = distance[u] + 1
                queue.append(v)
    return distance

graph = {"A": ["B"], "B": ["A", "C", "D"],
         "C": ["B"], "D": ["B"]}
assert bfs(graph, "A")["D"] == 2
```

## よくある誤解

- BFSとDFSはともに全頂点を訪問できますが、最短距離の保証はBFSにあります。
- Dijkstra法は負の辺を扱えません。
- トポロジカルソートは閉路のある有向グラフには存在しません。
- spanning treeは元の全辺を残す木ではなく、全頂点を含む辺の部分集合です。
- Hamilton路とEuler路は訪問対象が異なります。
- 無向グラフの次数は、自己ループなどの扱いを定義してから数えます。

## 演習問題

### ★ 基本

1. 頂点4、辺3で連結な無向グラフが木になる理由を説明してください。
2. 次数の合計と辺数の関係を、簡単なグラフで確認してください。

### ★★ 標準

3. 上のA-B-C-Dグラフで、Aから各頂点へのBFS距離を求めてください。
4. 依存関係 `A→C, B→C, C→D` のトポロジカル順序を一つ求めてください。

### ★★★ 応用

5. Dijkstra法が負辺で失敗する小さな例を作ってください。
6. 辺の重み `(A,B)=1,(A,C)=4,(B,C)=2` のMSTをKruskal法で求めてください。

### ★★★★ 発展

7. SNSのフォロー関係で、BFS距離が「知り合いを介した最小人数」を表す条件と表さない条件を整理してください。

## 解答と思考プロセス（詳しい解答）

1. 頂点数は4、辺数は3なので、`m=n-1`です。
   さらに問題文で連結と与えられているため、木の同値条件「連結かつ辺数`n-1`」を使えます。
   したがって、このグラフは木です。
   連結という条件がなければ、辺数が3でも二つの成分に分かれている可能性があるため、木とは結論できません。
2. 辺を一つ選ぶと、その両端の二頂点の次数がそれぞれ1増えます。
   したがって、辺がm本なら次数の合計は `2m` です。
   例えば辺`AB, BC`なら、次数はA:1、B:2、C:1で、合計4、`2m=4`となります。
3. 図の辺は`A-B, B-C, B-D`です。
   Aから開始するとAの距離は0、Bは1、Bから進むCとDは2です。
   よって `A:0, B:1, C:2, D:2`です。
4. CにはAとBの両方から矢印が入るため、Cより前にAとBを置く必要があります。
   その条件を満たす `A,B,C,D` と `B,A,C,D` は正しいトポロジカル順序です。
   DAGでは入次数0の候補が複数あるため、正解が一つとは限りません。
5. `A→B=10, A→C=1, C→B=-5`を考えます。
   Aからの暫定距離はBが10、Cが1なので、Dijkstra法はBよりCを先に確定します。
   Cを処理するとBの候補は`1-5=-4`になり、すでに確定したBの10より短くなります。
   このように確定済み距離が後から更新されるため、負辺があるとDijkstra法の前提が壊れます。
6. 辺を重み順に見ると、AB=1、BC=2、AC=4です。
   ABを採用し、BCを採用すると、A・B・Cが連結します。
   ACを加えると三角形の閉路になるため棄却します。
   採用辺の合計は`1+2=3`です。
7. 一回のフォローを有向辺として表し、すべての辺の重みを1とします。
   このときBFS距離は、始点から何本のフォロー辺をたどれば到達できるかを表します。
   逆方向のフォローを自動的に許すと意味が変わるため、有向グラフとして扱う必要があります。
   到達不能な利用者には有限の距離を割り当てず、`∞`または未到達として扱います。
