# Part 4　関係と関数

## この章でできるようになること

この章では、集合の要素どうしの結び付きと、入力から出力への対応を数学的に表す。

関数は「一つの入力に、出力が一つだけ決まる」仕組みであり、二項関係は「二つの要素の間に関係があるか」を表す仕組みである。

この二つを区別できると、データ分類、辞書、データベースの外部キー、依存関係、トポロジカルソートを同じ言葉で整理できる。

## Knowledge Map

```text
集合
 ├─ 関数、写像
 │    ├─ 定義域、終域、値域
 │    ├─ 単射、全射、全単射
 │    └─ 合成、逆関数
 │
 └─ 二項関係
      ├─ 反射的、対称的、反対称的、推移的
      ├─ 同値関係、同値類
      └─ 半順序、全順序
             │
             └─ 分類、DB、依存関係、辞書、グラフアルゴリズム
```

Part 3 で学んだ証明を使い、関数や関係がどの性質を持つかを段階的に判定する。

## 4.1 対応を矢印で見る

### 直感

関数を、左の集合から右の集合へ伸びる矢印の規則として考える。

左側は入力の候補、右側は出力の候補である。

この章では、`x∈A` を「`x` は集合 `A` の要素」、`A→B` を「`A` から `B` への関数」と読む。

また、`ℝ` は実数全体の集合、`A×A` は `A` の要素を二つ並べた順序対全体の集合を表す。

```text
定義域 A                 終域 B
  1  ───────────────→      a
  2  ───────────────→      b
  3  ───────────────→      b
```

この図では、1、2、3 はすべて矢印を一つずつ持つ。

2 と 3 が同じ `b` に向かってもよい。

一方、入力 1 から `a` と `b` の二本の矢印が出ていたら、関数ではない。

### 定義

関数 `f:A→B` とは、集合 `A` の各要素 `x` に対し、集合 `B` の要素 `f(x)` をただ一つ対応させる規則である。

- **定義域**：入力として許される集合 `A`。
- **終域**：出力が属すると約束する集合 `B`。
- **値域**：実際に出力された要素の集合 `f(A)`。
- **写像**：関数と同じ意味で使う語。

終域と値域は同じとは限らない。

例えば `f:{1,2,3}→{a,b,c}` が `f(1)=a,f(2)=b,f(3)=b` なら、終域は `{a,b,c}`、値域は `{a,b}` である。

### 最小例

```text
f: {1, 2, 3} → {a, b, c}
f(1)=a, f(2)=b, f(3)=b
```

この写像は関数である。

`c` が使われていないので、全射ではない。

2 と 3 が同じ出力なので、単射ではない。

### 関数ではない例

```text
g: {1, 2} → {a, b}
g(1)={a, b}
g(2)=a
```

`g(1)` が一つの要素ではなく二要素の集合なので、通常の関数としては定義されていない。

「出力が一つもない」場合も関数ではない。

### 手計算

`f(x)=2x+1`、定義域を `{0,1,2}`、終域を `{1,3,5,7}` とする。

```text
f(0)=1
f(1)=3
f(2)=5
```

値域は `{1,3,5}` である。

終域の `7` は候補に含まれるが、実際の値域には含まれない。

### 誤解

「値域は終域の別名」と考えてはいけない。

値域は実際に現れる出力、終域は設計上の出力の受け皿である。

同じ式 `2x+1` でも定義域や終域が変われば、単射性や全射性の判定が変わる。

## 4.2 単射、全射、全単射

### 単射

関数 `f:A→B` が**単射**であるとは、異なる入力が同じ出力にならないことである。

記号では、

```text
∀x1,x2∈A, f(x1)=f(x2) ⇒ x1=x2
```

と書く。

矢印図では、どの出力にも矢印が二本以上集まらない。

```text
A              B
1 ───────────→ a
2 ───────────→ b
3 ───────────→ c
```

### 全射

関数 `f:A→B` が**全射**であるとは、終域 `B` のすべての要素が少なくとも一つの入力から現れることである。

```text
∀y∈B, ∃x∈A, f(x)=y
```

単射の式では `x1,x2` が定義域 `A` に属し、全射の式では `y` が終域 `B` に属することが重要である。

### 全単射

単射かつ全射である関数を**全単射**という。

全単射は、入力と出力を一対一に対応させる。

有限集合で全単射があるとき、二つの集合の要素数は等しい。

### 具体例

`f:{1,2,3}→{a,b,c}`、`f(1)=a,f(2)=b,f(3)=c` は単射であり全射でもある。

したがって全単射である。

`g:{1,2,3}→{a,b}`、`g(1)=a,g(2)=b,g(3)=a` は全射だが単射ではない。

`h:{1,2}→{a,b,c}`、`h(1)=a,h(2)=b` は単射だが全射ではない。

### 判定のテンプレート

#### 単射を示す

```text
何を示すか：f(x1)=f(x2) なら x1=x2
定義：単射の定義を使う
使える定理：等式の変形
方法候補：出力が等しいと仮定する直接証明
骨格：f(x1)=f(x2) → 式を整理 → x1=x2
完全な証明：定義域の任意の x1,x2 で書く
```

#### 全射を示す

```text
何を示すか：任意の y∈B に対して、f(x)=y となる x∈A がある
定義：全射の定義を使う
使える定理：方程式を解く
方法候補：y を任意に取り、x を構成する
骨格：y を取る → f(x)=y となる x を作る → x∈A を確認
完全な証明：終域のすべての y を覆う
```

### 具体例：`f(x)=2x+1` の性質

`f:ℝ→ℝ`、`f(x)=2x+1` を考える。

#### 単射の証明

何を示すかは、`f(x1)=f(x2)` なら `x1=x2` である。

定義から、任意の実数 `x1,x2` を取る。

使える定理は、等式の両辺から同じ数を引き、0 でない数で割れることである。

方法候補は、出力が等しいと仮定する直接証明である。

骨格は、`2x1+1=2x2+1` から `x1=x2` を導くことになる。

完全な証明を書く。

```text
f(x1)=f(x2)
2x1+1=2x2+1
2x1=2x2
x1=x2
```

よって `f` は単射である。

#### 全射の証明

何を示すかは、任意の `y∈ℝ` に対して `f(x)=y` となる `x∈ℝ` の存在である。

定義から `f(x)=2x+1` を使う。

方法候補は、`2x+1=y` を `x` について解く構成である。

骨格は `x=(y−1)/2` を作ることになる。

任意の `y∈ℝ` を取る。

`x=(y−1)/2` と置くと、`x` は実数であり、

```text
f(x)=2((y−1)/2)+1=y−1+1=y
```

となる。

したがって任意の `y` が値域に入り、`f` は全射である。

よって `f` は全単射である。

### 誤り

単射は「異なる入力が異なる出力になる」と読むとよいが、証明では `f(x1)=f(x2)⇒x1=x2` の形が安全である。

全射は「入力と出力の個数が同じ」とは限らない。

無限集合では個数の直感が危険なので、任意の `y` に対する逆像を実際に構成する。

## 4.3 合成と逆関数

### 合成

関数 `f:A→B` と `g:B→C` があるとき、`g` の入力に `f` の出力を入れる関数を**合成**と呼び、`g∘f` と書く。

```text
A ─────f────→ B ─────g────→ C
└──────── g∘f ────────────→ C
```

定義は、

```text
(g∘f)(x)=g(f(x))
```

である。

右から先に `f` を適用することに注意する。

### 手計算

`f(x)=x+2`、`g(x)=3x` なら、

```text
(g∘f)(x)=g(x+2)=3(x+2)=3x+6
(f∘g)(x)=f(3x)=3x+2
```

一般には `g∘f` と `f∘g` は異なる。

### 逆関数

全単射 `f:A→B` に対して、`f(x)=y` の対応を逆向きにした関数を**逆関数**と呼び、`f^{-1}:B→A` と書く。

逆関数は、

```text
f^{-1}(f(x))=x
f(f^{-1}(y))=y
```

を満たす。

### 逆関数が存在する条件

関数 `f:A→B` が逆関数を持つことと、`f` が全単射であることは同値である。

#### 「全単射なら逆関数がある」の証明

何を示すかは、全単射 `f` に対して `f^{-1}:B→A` を定義できることである。

定義より、全射なので任意の `y∈B` に対して `f(x)=y` を満たす `x∈A` が存在する。

単射なので、その `x` は一意である。

使える定理は、存在と一意性がそろえば、`y` に対応する一つの `x` を関数として定められることである。

方法候補は、任意の `y` から逆像 `x` を構成する直接証明である。

骨格は、全射で存在、単射で一意性、よって逆関数を定義、である。

完全な証明では、任意の `y∈B` を取る。

全射により、`f(x)=y` を満たす `x∈A` が少なくとも一つ存在する。

もし `x1,x2` がともに `f(x1)=y`、`f(x2)=y` を満たすなら、`f(x1)=f(x2)` なので、単射により `x1=x2` である。

したがって、その `x` は一意に定まり、`f^{-1}(y)=x` と定義できる。

任意の `y` について定義できるので、`f^{-1}:B→A` は関数である。

定義から `f(f^{-1}(y))=y`、`f^{-1}(f(x))=x` も成り立つ。

よって全単射 `f` は逆関数を持つ。

逆に、逆関数を持つ関数が単射かつ全射であることも、上の二つの等式から示せる。

実際、`f(x1)=f(x2)` なら、両辺に `f^{-1}` を適用して `x1=x2` となるので単射である。

任意の `y∈B` に対して `x=f^{-1}(y)` と置けば `f(x)=y` なので全射である。

### 具体例

`f:ℝ→ℝ`、`f(x)=2x+1` の逆関数を求める。

```text
y=2x+1
y−1=2x
x=(y−1)/2
```

変数名を戻すと、

```text
f^{-1}(x)=(x−1)/2
```

である。

`f^{-1}(f(3))=(7−1)/2=3` となり、逆向きの対応を確認できる。

### 誤解

式を解いて形が出たからといって、必ず逆関数があるとは限らない。

例えば `f(x)=x^2` を `ℝ→ℝ` とすると、`f(1)=f(-1)` で単射ではなく、負の数を出力しないので全射でもない。

定義域を `[0,∞)`、終域を `[0,∞)` に変えれば、逆関数 `√x` を持つ。

## 4.4 二項関係と四つの性質

### 直感

関数は「各入力から出る矢印が一本だけ」という強い制約を持つ。

二項関係は、矢印が複数本でも、一本もなくてもよい。

集合 `A` 上の**二項関係** `R` とは、`A×A` の部分集合、つまり `R⊆A×A` である。

したがって、関係に含まれる順序対 `(a,b)` は必ず `a,b∈A` を満たす。

`aRb` は `(a,b)∈R` を意味する。

以下の四つの性質では、特に断らない限り `a,b,c∈A` とする。

```text
A={1,2,3}
R={(1,1),(2,2),(3,3),(1,2)}

1 ───→ 1
│
└────→ 2
2 ───→ 2
3 ───→ 3
```

関係は、順序対を表す表、隣接行列、有向グラフとしても表現できる。

### 反射性

関係 `R` が**反射的**であるとは、任意の `a∈A` について `aRa` が成り立つことである。

全要素に自己ループがある。

### 対称性

`R` が**対称的**であるとは、`aRb` なら `bRa` であることをいう。

つまり、任意の `a,b∈A` について `aRb⇒bRa` である。

友人関係や「同じ分類に属する」は対称的になりやすい。

### 反対称性

`R` が**反対称的**であるとは、`aRb` かつ `bRa` なら `a=b` であることをいう。

つまり、任意の `a,b∈A` について `aRb∧bRa⇒a=b` である。

「反対称」は「対称でない」という意味ではない。

異なる要素どうしの往復関係を禁止する性質である。

`≤` は反対称的である。

`a≤b` かつ `b≤a` なら `a=b` だからである。

### 推移性

`R` が**推移的**であるとは、`aRb` かつ `bRc` なら `aRc` であることをいう。

つまり、任意の `a,b,c∈A` について `aRb∧bRc⇒aRc` である。

依存関係や「以下である」は推移的に設計されることが多い。

### 判定表

| 性質 | 形 | 自己関係が必要か | 往復関係 |
| --- | --- | --- | --- |
| 反射的 | `∀a∈A, aRa` | 必要 | 問わない |
| 対称的 | `∀a,b∈A, aRb⇒bRa` | 問わない | 往復を要求 |
| 反対称的 | `∀a,b∈A, (aRb∧bRa)⇒a=b` | 問わない | 異なる要素の往復を禁止 |
| 推移的 | `∀a,b,c∈A, (aRb∧bRc)⇒aRc` | 問わない | 2段の関係を短絡 |

### 具体例：`≤`

実数上の `≤` は反射的である。

任意の `a` について `a≤a` だからである。

対称的ではない。

`1≤2` だが `2≤1` ではない。

反対称的である。

`a≤b` かつ `b≤a` なら `a=b` である。

推移的である。

`a≤b` かつ `b≤c` なら `a≤c` である。

### 関係の性質を証明する段階

例えば「整数の同じ偶奇関係は同値関係である」を示すとする。

何を示すかは、`aRb` を「`a` と `b` の偶奇が同じ」と定義した関係について、四つの性質のうち反射性、対称性、推移性を示すことである。

定義から、`aRb` は「ある整数 `k` を使い `a-b=2k`」と同値である。

使える定理は、整数の差の和と符号反転も整数であることである。

方法候補は各性質の定義に直接代入する方法である。

骨格は次のとおりである。

```text
反射：a−a=0=2×0
対称：a−b=2k → b−a=−2k
推移：a−b=2k, b−c=2l → a−c=2(k+l)
```

完全な証明を書く。

反射性について、任意の整数 `a` を取ると `a-a=0=2×0` である。

したがって `aRa` が成り立つ。

対称性について、`aRb` とする。

すると `a-b=2k` となる整数 `k` がある。

両辺の符号を反転すると `b-a=2(-k)` であり、`-k` は整数なので `bRa` である。

推移性について、`aRb` かつ `bRc` とする。

すると `a-b=2k`、`b-c=2l` となる整数 `k,l` がある。

加えると `a-c=2(k+l)` であり、`k+l` は整数なので `aRc` である。

以上により、この関係は反射的、対称的、推移的である。

反対称性は一般には成り立たない。

例えば 1 と 3 は偶奇が同じで、`1R3` かつ `3R1` だが、`1≠3` だからである。

## 4.5 同値関係と同値類

### 定義

反射的、対称的、推移的な二項関係を**同値関係**という。

同値関係は「同じ種類」とみなす基準を表す。

要素 `a` の**同値類**を、

```text
[a] = {x∈A | xRa}
```

と定義する。

### 直感

同値関係は、集合を重なりのないグループへ分ける。

同じグループの中では互いに同値であり、異なるグループは混ざらない。

```text
A={0,1,2,3,4,5}
偶奇が同じ

偶数類 {0,2,4}     奇数類 {1,3,5}
```

### 具体例：3 で割った余り

整数上で `aRb` を「`a-b` が 3 の倍数」と定義する。

これは同値関係である。

同値類は、

```text
[0] = {...,-6,-3,0,3,6,...}
[1] = {...,-5,-2,1,4,7,...}
[2] = {...,-4,-1,2,5,8,...}
```

となる。

手計算では、`8R2` は `8-2=6=3×2` なので真である。

`8R3` は `8-3=5` が 3 の倍数でないので偽である。

### データ分類への接続

顧客の住所を「同じ都道府県」、文書を「同じカテゴリ」、画像を「同じラベル」とみなすとき、分類基準が同値関係に近いかを確認できる。

同じレコードが二つの分類に入ったり、A と B は同じで B と C も同じなのに A と C が違ったりすると、分類が安定しない。

同値類は、重複排除、クラスタの代表値、カテゴリごとの集計単位として使える。

### 誤解

「似ている」は同値関係とは限らない。

人 A が人 B より背が高く、B が C より背が高くても、A と C の関係を「似ている」とは限らない。

特に推移性が壊れやすいので、分類へ使う前に三つの要素で確認する。

## 4.6 半順序と全順序

### 半順序

集合 `A` 上の関係 `≤` が反射的、反対称的、推移的なら、**半順序**という。

記号で書くと、次の三条件をすべて満たす関係である。

```text
∀a∈A, a≤a
∀a,b∈A, (a≤b∧b≤a)⇒a=b
∀a,b,c∈A, (a≤b∧b≤c)⇒a≤c
```

半順序では、すべての二要素を比較できる必要はない。

集合の包含関係 `⊆` は半順序である。

`{a}` と `{b}` は、`a≠b` ならどちらも他方を含まないため比較不能である。

```text
      {a,b}
       /  \
     {a}  {b}
       \  /
        ∅
```

この図はハッセ図の簡略形であり、下から上へ行くほど包含が大きい。

### 全順序

半順序に加えて、任意の `a,b` が比較可能、つまり `a≤b` または `b≤a` が成り立つとき**全順序**という。

記号では、半順序の三条件に加えて、

```text
∀a,b∈A, a≤b∨b≤a
```

を満たす。

整数の通常の大小関係は全順序である。

集合の包含関係は一般には全順序ではない。

### 依存関係への接続

ソフトウェアの依存関係で、「タスク A が終わってからタスク B を実行する」を `A≺B` と書く。

直接の依存辺だけを保存するグラフは、通常は推移的ではない。

例えば `fetch→parse` と `parse→train` を保存しても、`fetch→train` の辺を明示的には保存しないことがある。

一方、「依存関係をたどって到達できる」を `A≺B` と定義し、循環がないなら、この `≺` は非反射的で推移的な関係になる。

このような関係を**厳密半順序**と呼ぶ。

非反射的とは、任意の `A` について `A≺A` が成り立たないことである。

`A≼B` を「`A=B` または `A≺B`」と定義すれば、反射的、反対称的、推移的な半順序になる。

```text
fetch ───→ parse ───→ train
   \                     ↑
    └────→ validate ─────┘
```

`fetch` と `validate` のように、直接比較する必要がないタスクがあるため、全順序ではなく半順序として扱うのが自然である。

### トポロジカルソート

有限な有向非巡回グラフの依存関係から、制約を守る一列の実行順を作ることをトポロジカルソートという。

一列に並べた結果は、依存制約を保つ全順序（元の半順序の線形拡張）の一例である。

元の依存関係では比較不要なタスクもあるため、複数の有効な実行順序が存在することがある。

```text
indegree を計算
0 の頂点をキューへ入れる
キューから一つ取り出し、出力へ追加
その頂点から出る辺を削除し、indegree が 0 になった頂点を追加
すべて出力できれば成功、残れば循環
```

## 4.7 辞書とデータベースでの表現

### 辞書は部分的な関数

Python の辞書 `dict` は、キーから値への対応を表す。

キーが重複しないので、格納されたキーの集合から値の集合への関数とみなせる。

```python
scores = {"Aki": 80, "Ren": 92}
```

この辞書は、`{"Aki", "Ren"}` から整数への関数である。

「存在しないキー」は、全体の名前集合から整数への全関数ではなく、登録済みキーだけを定義域とする部分関数として理解できる。

### DBの外部キーは関数になりやすい

各注文が一つの顧客に属するなら、注文 ID から顧客 ID への対応は関数である。

一人の顧客が複数の注文を持つことは、逆向きの顧客 ID から注文 ID への対応を関数にしない。

```text
注文 101 ───→ 顧客 C01
注文 102 ───→ 顧客 C01
注文 103 ───→ 顧客 C02
```

これは注文から顧客への関数だが、顧客から注文への関係は一対多である。

### 多対多は関係として表す

学生と講義の履修は、多対多の関係である。

中間テーブル `enrollments(student_id, course_id)` は、二項関係の有限表現とみなせる。

```text
student_id | course_id
-----------+----------
S01        | C01
S01        | C02
S02        | C01
```

同じ行の重複を禁止すれば、関係の集合として扱える。

### 分類の同値関係

メールアドレスを小文字化し、前後空白を除去した結果が同じなら同じアカウントとみなす、という規則は、正規化後の値に対する同値関係として設計できる。

ただし、正規化が推移性を壊すなら、重複排除の結果が入力順に依存する。

## 4.8 Pythonで性質を判定する

### 関係の表現

有限集合 `A` 上の関係を、順序対の集合で表す。

```python
from itertools import product


def is_reflexive(elements: set[int], relation: set[tuple[int, int]]) -> bool:
    return all((a, a) in relation for a in elements)


def is_symmetric(relation: set[tuple[int, int]]) -> bool:
    return all((b, a) in relation for a, b in relation)


def is_antisymmetric(relation: set[tuple[int, int]]) -> bool:
    return all(a == b or (b, a) not in relation for a, b in relation)


def is_transitive(relation: set[tuple[int, int]]) -> bool:
    return all(
        (a, c) in relation
        for a, b in relation
        for x, c in relation
        if b == x
    )


elements = {0, 1, 2, 3}
same_parity = {
    (a, b) for a, b in product(elements, repeat=2) if (a - b) % 2 == 0
}

assert is_reflexive(elements, same_parity)
assert is_symmetric(same_parity)
assert is_transitive(same_parity)
assert not is_antisymmetric(same_parity)
```

`is_transitive` は、`(a,b)` と `(b,c)` の組だけを調べるように書いてもよい。

上のコードでは `x==b` の条件で同じことを表している。

コードの判定は、指定した有限集合についての検査である。

整数全体など無限集合の性質を証明するには、Part 3 の証明が必要である。

### 単射と全射の判定

```python
def is_injective(mapping: dict[str, str]) -> bool:
    return len(mapping.values()) == len(set(mapping.values()))


def is_surjective(
    mapping: dict[str, str], codomain: set[str]
) -> bool:
    return set(mapping.values()) == codomain


mapping = {"one": "a", "two": "b", "three": "b"}
assert not is_injective(mapping)
assert is_surjective(mapping, {"a", "b"})
```

辞書は登録された定義域の各キーに値が一つあるため、辞書としては関数の条件を満たす。

ただし、未登録キーをどう扱うかは別の仕様であり、`None` を返す設計なら終域へ `None` を含めるか決める必要がある。

## 4.9 よくある誤解

### 「反対称」は「対称でない」ではない

反対称性は、異なる要素の往復を禁止する条件である。

対称性と反対称性は、同時に成り立つこともある。

例えば等号関係 `=` は対称的であり、反対称的でもある。

### 全射の終域を勝手に値域へ変えない

関数の性質は `f:A→B` という終域まで含めて決まる。

`f:ℝ→ℝ, f(x)=x^2` は全射でないが、`f:ℝ→[0,∞), f(x)=x^2` なら全射である。

### 関係は関数より一般的

関数は各入力に出力を一つだけ割り当てる。

関係には、その制限がない。

「顧客が注文を持つ」は一人の顧客に複数注文があるので、顧客から注文への関数ではなく関係である。

### 半順序は並び順そのものではない

半順序は比較の制約を表す。

そこから一列の順序を一つ選ぶには、トポロジカルソートなど追加の手続きが必要である。

## 4.10 演習問題

### 問題1　★

`f:{1,2,3}→{a,b,c}`、`f(1)=a,f(2)=b,f(3)=b` の値域、単射性、全射性を答えよ。

#### 解答と思考の要点

まず実際の出力を列挙する。

値域は `{a,b}` である。

2 と 3 が同じ `b` に写るので単射ではない。

終域の `c` が値域にないので全射ではない。

### 問題2　★★

`f:ℝ→ℝ`、`f(x)=3x−2` が全単射であることを示し、逆関数を求めよ。

#### 解答と思考の要点

単射は `3x1−2=3x2−2` から `x1=x2` を示す。

全射は任意の `y` に対し `x=(y+2)/3` を構成する。

したがって全単射であり、`f^{-1}(x)=(x+2)/3` である。

### 問題3　★★

集合 `A={1,2,3}` 上の関係 `R={(1,1),(2,2),(3,3),(1,2),(2,1)}` について、四つの性質を判定せよ。

#### 解答と思考の要点

自己対 `(1,1),(2,2),(3,3)` があるので反射的である。

`(1,2)` と `(2,1)` がそろい、他の非対角対がないので対称的である。

異なる 1 と 2 の往復があるので反対称的ではない。

`1R2` かつ `2R1` から `1R1` が得られ、他の二段関係も閉じているので推移的である。

### 問題4　★★★

整数上の「差が 5 の倍数である」という関係が同値関係であることを示し、`[2]` を書け。

#### 解答と思考の要点

反射性は `a-a=0`、対称性は符号反転、推移性は倍数どうしの和で示す。

`[2]` は `{...,−8,−3,2,7,12,...}` である。

### 問題5　★★★

集合 `{a,b}` の包含関係が半順序だが全順序でないことを説明せよ。

#### 解答と思考の要点

包含関係は任意の集合について反射的、反対称的、推移的なので半順序である。

しかし `{a}` と `{b}` は、`a≠b` なら `{a}⊄{b}` かつ `{b}⊄{a}` である。

比較できない二要素があるので全順序ではない。

### 問題6　★★★★

関数 `f:A→B` と `g:B→C` が単射なら、合成 `g∘f` も単射であることを証明せよ。

#### 解答と思考の要点

何を示すかは、`(g∘f)(x1)=(g∘f)(x2)` なら `x1=x2` である。

定義を展開すると `g(f(x1))=g(f(x2))` となる。

まず `g` の単射性から `f(x1)=f(x2)`、次に `f` の単射性から `x1=x2` を得る。

よって合成は単射である。

## 4.11 理解度確認

- 定義域、終域、値域を、矢印図で区別できるか。
- 単射、全射、全単射の定義を量化記号で書けるか。
- 合成 `g∘f` を右から適用する理由を説明できるか。
- 逆関数の存在に、全射による存在と単射による一意性が必要な理由を言えるか。
- 反射的、対称的、反対称的、推移的を、それぞれ一つの式で書けるか。
- 同値関係が分類を作る理由を、同値類で説明できるか。
- 半順序と全順序の違いを、比較不能な要素で説明できるか。
- 顧客と注文、学生と講義、タスクと依存先のどれが関数でどれが関係かを判定できるか。

## 4.12 章間のつながり

Part 3 の量化は、関数の性質を正確に書くために使う。

例えば全射は「任意の出力 `y` に対して、ある入力 `x` が存在する」という `∀y∃x` の主張である。

逆関数の証明では、全射から存在を、単射から一意性を得る。

同値関係の証明では、反射性、対称性、推移性を一つずつ直接証明する。

半順序の依存関係からトポロジカルソートを作るときは、関係の推移性と循環の有無がアルゴリズムの正しさに関わる。
