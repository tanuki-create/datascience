# Part 9 整数論

## この章でできるようになること

この章では、整数を対象にした計算の規則を、具体例から少しずつ一般化します。

- 「(a) は (b) を割り切る」という整除を、割り算の余りと結び付けて説明できる。
- 約数、倍数、素数、素因数分解を使って整数の構造を表現できる。
- GCD（最大公約数）と LCM（最小公倍数）を求め、Euclid（ユークリッド）の互除法を手計算できる。
- 合同式と `mod` を、時計のような「余りの世界」として扱える。
- Fermat（フェルマー）の小定理と Euler（オイラー）の φ 関数が、なぜ逆元や RSA につながるかを説明できる。
- ハッシュと RSA の計算を小さな整数で追跡し、玩具例と実運用を区別できる。

ここで扱う暗号の数値は理解のためのものです。
実際のシステムでは、暗号ライブラリ、適切な鍵長、乱数、パディングの設計が必要です。

## 9.1 整数を「割り切れる構造」として見る

### 直感

12個のクッキーを、同じ個数ずつ配る場面を考えます。
2人、3人、4人、6人、12人には余りなく配れますが、5人には配れません。

この「余りが出ない」という関係を、整数論では整除で表します。

```
12個のものを等分する

2人:  12 = 2 × 6  → 余り 0
3人:  12 = 3 × 4  → 余り 0
5人:  12 = 5 × 2 + 2  → 余り 2
```

整数論の重要な視点は、数の大きさだけでなく、どの数がどの数を割り切るかを見ることです。
この関係は、配列のハッシュ表、周期処理、誤り検出、公開鍵暗号にも現れます。

### 定義

**整除**：整数 (a,b) について、ある整数 (k) を使って (b=ak) と書けるとき、(a) は (b) を割り切るといい、(a\mid b) と書きます。

ここで (a) を (b) の**約数**、(b) を (a) の**倍数**と呼びます。

例えば、(3\mid 12) です。
なぜなら (12=3\times4) と書けるからです。

一方、(5\nmid 12) です。
(12=5k) となる整数 (k) は存在しません。

### 最小例

18の正の約数を列挙します。

| (d) | (18\div d) | 判定 |
|---:|---:|---|
| 1 | 18 | 約数 |
| 2 | 9 | 約数 |
| 3 | 6 | 約数 |
| 4 | 4.5 | 約数ではない |
| 6 | 3 | 約数 |
| 9 | 2 | 約数 |
| 18 | 1 | 約数 |

したがって、18の正の約数は (1,2,3,6,9,18) です。

### 手計算

24が6で割り切れるかを確認します。

1. (24\div6=4) と計算する。
2. 商が整数なので、余りは0である。
3. よって (6\mid24) である。

割り算を小数で終わらせず、(24=6\times4) と書き直すと、整除の定義を直接確認できます。

### 証明段階

整除の基本性質を一つ証明します。

主張：(a\mid b) かつ (a\mid c) なら、任意の整数 (x,y) に対して (a\mid (bx+cy)) です。

証明の段階は次の通りです。

1. 整除の定義から (b=ak, c=a\ell) と置く。
2. (bx+cy) に代入する。
3. (a) をくくり出し、残りが整数であることを確認する。

### 完全証明

(a\mid b) なので、ある整数 (k) が存在して (b=ak) です。

同様に、(a\mid c) なので、ある整数 \(k_2\) が存在して \(c=ak_2\) です。

したがって、

\[
bx+cy=(ak)x+(a\ell)y=a(kx+\ell y)
\]

です。

(k,x,k_2,y) はすべて整数なので、\(kx+k_2y\) も整数です。

よって整除の定義から (a\mid (bx+cy)) です。

### よくある誤解

「割り切れる」と「商が小数でも計算できる」は同じではありません。

例えば (5\mid12) ではありません。
(12\div5=2.4) と計算できても、余りなく整数個に分けられないからです。

また、(a\mid b) は「(a) が (b) より小さい」という意味でもありません。

(12\mid12) は成り立ちますし、(1\mid12) も成り立ちます。

## 9.2 素数と素因数分解

### 直感

整数を「これ以上分解できない部品」に分けます。
例えば12は、(2\times2\times3) と書けます。
2と3は、1と自分自身以外の正の約数を持たないので、部品として扱いやすい数です。

```
12
├─ 2 × 6
│     └─ 2 × 3
└─ 2 × 2 × 3
```

この部品を素数といい、素数の積に分解することを素因数分解といいます。

### 定義

**素数**：2以上の整数で、正の約数が1と自分自身だけである数です。

2, 3, 5, 7, 11, 13 は素数です。

1は素数ではありません。
1を素数に含めると、素因数分解の一意性が壊れるためです。

例えば、6は (2\times3) とも (1\times2\times3) とも書けますが、1は部品として数えない約束にします。

**合成数**：2以上で、素数ではない整数です。

4, 6, 8, 9, 10 は合成数です。

### 最小例

84を素因数分解します。

\[
84=2\times42=2\times2\times21=2^2\times3\times7
\]

したがって、

\[
84=2^2\times3\times7
\]

です。

### 手計算

素因数分解では、小さい素数から順番に割ります。

```
84 ÷ 2 = 42
42 ÷ 2 = 21
21 ÷ 3 = 7
 7 ÷ 7 = 1
```

割った素数を左から並べると、(2,2,3,7) です。

### 証明段階

すべての2以上の整数が素数の積に分解できることを確認します。

1. (n=2) なら、(n) 自身が素数なので終わり。
2. (n) が素数でなければ、(n=ab) と書ける。
3. (a,b) は (n) より小さいので、帰納法の仮定を使ってそれぞれ素数の積に分解する。
4. その積を合わせれば、(n) も素数の積になる。

### 完全証明

主張：2以上のすべての整数は、有限個の素数の積で表せます。

数学的帰納法で証明します。

最初に (n=2) を考えます。
2は素数なので、2という一つの素数の積として表せます。

次に、2以上 (n-1) 以下の整数がすべて素数の積で表せると仮定します。

(n) が素数なら、(n) 自身が素数の積です。

(n) が合成数なら、(n=ab) と書けます。
このとき (a,b) は1より大きく、(n) より小さい整数です。

帰納法の仮定により、(a) と (b) はそれぞれ素数の積で表せます。

したがって (n=ab) も、二つの素数積をつないだ素数の積で表せます。

以上から、すべての (n\ge2) は素数の積に分解できます。

素因数の順序を除けば分解が一意であることは、後のGCDやLCMの計算を支えます。

### よくある誤解

「奇数はすべて素数」ではありません。

9は奇数ですが、(9=3\times3) なので合成数です。

「1は素数」でもありません。

素数は、1と自分自身という二つの異なる正の約数を持つ数です。

## 9.3 GCD、LCM、Euclid互除法

### 直感

24個と36個のものを、同じ人数に、余りなく、できるだけ多く配りたいとします。
このとき人数として使える最大の数がGCDです。

反対に、24日周期と36日周期のイベントが同じ日に再び起きるまでの最小日数がLCMです。

### 定義

**GCD（最大公約数）**：二つ以上の整数に共通する正の約数のうち、最大のものです。

**LCM（最小公倍数）**：二つ以上の正の整数に共通する正の倍数のうち、最小のものです。

24と36の約数を並べます。

| 数 | 正の約数 |
|---:|---|
| 24 | 1, 2, 3, 4, 6, 8, 12, 24 |
| 36 | 1, 2, 3, 4, 6, 9, 12, 18, 36 |

共通する約数は (1,2,3,4,6,12) なので、

\[
\gcd(24,36)=12
\]

です。

### 最小例

素因数分解を使う方法を示します。

\[
24=2^3\times3,
\qquad
36=2^2\times3^2
\]

GCDでは共通する素因数の指数の小さい方を選びます。

\[
\gcd(24,36)=2^2\times3=12
\]

LCMでは現れる素因数の指数の大きい方を選びます。

\[
\operatorname{lcm}(24,36)=2^3\times3^2=72
\]

### Euclid互除法の手計算

Euclid互除法は、余りを使ってGCDを小さな問題へ変換します。

\[
36=24\times1+12
\]

したがって、36と24の共通約数は、24と12の共通約数と同じです。

次に、

\[
24=12\times2+0
\]

となるので、最後の0でない余り12がGCDです。

```
(36, 24)
   ↓ 36 = 24×1 + 12
(24, 12)
   ↓ 24 = 12×2 + 0
(12, 0) → gcd = 12
```

### なぜ余りを使えるのか

(a=bq+r) とします。

ある数 (d) が (a) と (b) の両方を割り切るなら、

\[
r=a-bq
\]

も割り切ります。

逆に、(d) が (b) と (r) を割り切るなら、(a=bq+r) も割り切ります。

したがって、(a,b) と (b,r) は同じ共通約数を持ちます。

### 証明段階

Euclid互除法の正しさを、次の主張として証明します。

主張：\(\gcd(a,b)=\gcd(b,r)\) です。

1. \(\gcd(a,b)\) の任意の公約数が \(r\) も割ることを示す。
2. \(\gcd(b,r)\) の任意の公約数が \(a\) も割ることを示す。
3. 二つの公約数集合が一致するので、最大のものも一致する。

### 完全証明

(d) を (a,b) の公約数とします。

つまり (d\mid a) かつ (d\mid b) です。

\[
r=a-bq
\]

であり、整除の基本性質から (d\mid r) です。

したがって、(a,b) の公約数はすべて (b,r) の公約数です。

逆に、(d\mid b) かつ (d\mid r) とします。

\[
a=bq+r
\]

なので、同じ基本性質から (d\mid a) です。

したがって、(b,r) の公約数はすべて (a,b) の公約数です。

二つの組は同じ公約数集合を持つため、最大公約数も等しくなります。

\[
\gcd(a,b)=\gcd(b,r)
\]

### GCDとLCMの関係

正の整数 (a,b) について、

\[
\gcd(a,b)\times\operatorname{lcm}(a,b)=ab
\]

が成り立ちます。

24と36なら、

\[
12\times72=864=24\times36
\]

です。

これはLCMを確認する検算にも使えます。

### よくある誤解

Euclid互除法で「最初に出た余り」を答えにしません。

最後の0でない余りがGCDです。

また、GCDは「二つの数の小さい方」ではありません。

例えば \(\gcd(18,30)=6\) であり、18ではありません。

## 9.4 合同式と `mod`

### 直感

時計では、12時から13時間後は1時です。
時刻を12で割った余りだけ残すと、

\[
13\equiv1\pmod{12}
\]

と書けます。

合同式は、二つの数が「同じ余り」を持つことを表します。

```
整数:  ... -1   0   1   ...  11   12   13   14 ...
mod 12: ... 11   0   1   ...  11    0    1    2 ...
```

### 定義

**合同式**：正の整数 (m) に対して、(a-b) が (m) の倍数なら、(a) と (b) は法 (m) で合同といい、

\[
a\equiv b\pmod m
\]

と書きます。

これは、(a) と (b) を (m) で割った余りが等しいことと同値です。

**mod演算**：`a mod m` は、(a) を (m) で割った余りを返す演算です。

例えば、

\[
17\bmod5=2,
\qquad
17\equiv2\pmod5
\]

です。

### 最小例

\[
38\equiv3\pmod7
\]

です。
なぜなら、(38=7\times5+3) だからです。

差を取っても、

\[
38-3=35=7\times5
\]

となります。

### 合同式の計算規則

\[
a\equiv b\pmod m,\quad c\equiv d\pmod m
\]

なら、

\[
a+c\equiv b+d\pmod m
\]

および

\[
ac\equiv bd\pmod m
\]

です。

例えば、

\[
38\times27\pmod7
\]

を計算するとき、38を3、27を6に置き換えられます。

\[
38\times27\equiv3\times6=18\equiv4\pmod7
\]

### 手計算

\(2^{10}\bmod1000\) を求めます。

\[
2^{10}=1024
\]

なので、

\[
2^{10}\bmod1000=24
\]

です。

大きな指数では、途中で余りを取ります。

\[
2^2=4,
\quad2^4=16,
\quad2^8=256
\]

\[
2^{10}=2^8\times2^2\equiv256\times4=1024\equiv24\pmod{1000}
\]

途中で `mod` を取っても答えは変わりません。

### 逆元と割り算の注意

通常の割り算と違い、合同式ではいつでも割れるわけではありません。

(a) の法 (m) における**逆元**とは、

\[
ax\equiv1\pmod m
\]

を満たす (x) です。

逆元が存在する条件は、

\[
\gcd(a,m)=1
\]

です。

例えば、7の11を法とする逆元は8です。

\[
7\times8=56\equiv1\pmod{11}
\]

一方、2の4を法とする逆元はありません。
2の倍数はすべて偶数であり、4で割った余りが1になることはないからです。

### よくある誤解

「合同式の両辺を同じ数で割ればよい」とは限りません。

例えば、

\[
2x\equiv2\pmod6
\]

から、2で割って (x\equiv1\pmod6) とするのは誤りです。

実際には (x\equiv1\pmod3) であり、法も変わります。

安全に割るには、割る数が法と互いに素であることを確認します。

## 9.5 Fermatの小定理とEulerのφ関数

### 直感

素数を法にすると、0以外の余りは掛け算に関して巡回しやすくなります。
例えば法7で1から6を考えると、3を掛けた結果は次のように並びます。

| (x) | 1 | 2 | 3 | 4 | 5 | 6 |
|---:|---:|---:|---:|---:|---:|---:|
| (3x\bmod7) | 3 | 6 | 2 | 5 | 1 | 4 |

0以外の余りが重複せず、1から6を並べ替えています。
この事実が、指数を短くする定理を生みます。

### Fermatの小定理

素数 (p) と、(p) の倍数ではない整数 (a) に対して、

\[
a^{p-1}\equiv1\pmod p
\]

が成り立ちます。

例えば、

\[
3^6=729\equiv1\pmod7
\]

です。

同値な形として、任意の整数 (a) について、

\[
a^p\equiv a\pmod p
\]

も成り立ちます。

### 証明段階

(a) と (p) が互いに素である場合を証明します。

1. (1,2,\ldots,p-1) に (a) を掛けた余りを並べる。
2. それらが0ではなく、互いに異なることを示す。
3. 並べ替えなので積が等しいと置く。
4. (a^{p-1}) を消去する。
5. 逆元が存在することを使う。

### 完全証明

集合

\[
S=\{1,2,\ldots,p-1\}
\]

を考えます。

(a) は (p) の倍数ではないので、(ax\equiv0\pmod p) となる (x\in S) はありません。

また、(ax\equiv ay\pmod p) と仮定すると、

\[
a(x-y)\equiv0\pmod p
\]

です。

\(\gcd(a,p)=1\) なので、\(a\) は法 \(p\) で逆元を持ちます。
両辺にその逆元を掛けると (x\equiv y\pmod p) です。

(x,y) は1から (p-1) までなので、(x=y) です。

したがって、

\[
a,2a,\ldots,(p-1)a
\]

の余りは、0ではなく、互いに異なる (p-1) 個の値です。

つまり、これらは (1,2,\ldots,p-1) の並べ替えです。

積を取ると、

\[
(a\cdot1)(a\cdot2)\cdots(a\cdot(p-1))
\equiv1\cdot2\cdots(p-1)\pmod p
\]

です。

左辺は、

\[
a^{p-1}(p-1)!
\]

です。

((p-1)!) は (p) と互いに素なので、法 (p) で逆元を持ちます。
両辺からこれを消去すると、

\[
a^{p-1}\equiv1\pmod p
\]

を得ます。

### Eulerのφ関数

**Eulerのφ関数**（オイラーのトーシェント関数）\(\varphi(n)\) は、1以上 \(n\) 以下の整数のうち、\(n\) と互いに素なものの個数です。

例えば、

\[
1,2,3,4,5,6
\]

のうち6と互いに素なのは1と5なので、

\[
\varphi(6)=2
\]

です。

素数 (p) なら、1から (p-1) まではすべて互いに素なので、

\[
\varphi(p)=p-1
\]

です。

### φ関数の計算

素因数分解が

\[
n=p_1^{e_1}p_2^{e_2}\cdots p_r^{e_r}
\]

なら、

\[
\varphi(n)=n\prod_{i=1}^{r}\left(1-\frac1{p_i}\right)
\]

です。

例えば、(12=2^2\times3) なので、

\[
\varphi(12)=12\left(1-\frac12\right)\left(1-\frac13\right)=4
\]

です。

実際、1から12までで12と互いに素なのは1,5,7,11の4個です。

### Eulerの定理

\(\gcd(a,n)=1\) なら、

\[
a^{\varphi(n)}\equiv1\pmod n
\]

です。

Fermatの小定理は、(n) が素数のときのEulerの定理です。

### よくある誤解

Fermatの小定理は、法が合成数でもそのまま使えるわけではありません。

また、(a^{p-1}\equiv1\pmod p) には (p\nmid a) という条件があります。

例えば (0^6\equiv0\pmod7) であり、1ではありません。

## 9.6 整数論からハッシュへ

### 直感

大量のデータを、小さな配列のどこに置くか決めたいとします。
整数のキーを配列サイズで割った余りを使えば、位置を高速に決められます。

```
キー  0  1  2  3  4  5  6  7  8 ...
      │  │  │  │  │  │  │  │  │
      └──┴──┴──┴──┴──┴──┴──┴──┴──→ mod 5

バケット 0  1  2  3  4
```

### 数学的説明

配列のバケット数を (m)、整数キーを (k) とすると、単純なハッシュ位置は、

\[
h(k)=k\bmod m
\]

で表せます。

例えば (m=5) なら、12と17はどちらもバケット2です。

\[
12\bmod5=2,
\qquad
17\bmod5=2
\]

この現象を**衝突**と呼びます。

衝突はバグではなく、キーの集合よりバケット数が小さい限り避けられない場合があります。
連結リスト、オープンアドレス法、再ハッシュなどで解決します。

### CS応用

ハッシュ表の添字計算は整数論の最も身近な応用です。

ただし、通常のハッシュ表のハッシュ関数と、パスワード保存に使う暗号学的ハッシュ関数は目的が異なります。

| 用途 | 重視する性質 | 例 |
|---|---|---|
| ハッシュ表 | 速さ、偏りの少なさ | 配列の添字 |
| 改ざん検出 | 入力の違いを見つけにくくする | SHA-256 |
| パスワード保存 | 総当たりを遅くする | Argon2など |

単純な `key % size` をパスワード保存に使ってはいけません。

## 9.7 RSAと公開鍵暗号

### 直感

RSAは、掛け算は簡単だが、巨大な積を素因数分解するのは難しいという性質を利用します。

```
公開情報: n = p × q, e
秘密情報: d

暗号化: c = m^e mod n
復号  : m = c^d mod n
```

公開鍵で暗号化したデータを、対応する秘密鍵で復号できます。

### 玩具例

小さな素数 (p=5, q=11) を選びます。

\[
n=pq=55
\]

\[
\varphi(n)=(p-1)(q-1)=4\times10=40
\]

公開指数を (e=3) とします。

\(\gcd(3,40)=1\) なので、3の逆元を40を法として求められます。

\[
3\times27=81\equiv1\pmod{40}
\]

よって秘密指数は (d=27) です。

公開鍵は ((n,e)=(55,3))、秘密鍵は ((n,d)=(55,27)) です。

メッセージを (m=7) とします。

暗号化は、

\[
c=7^3\bmod55=343\bmod55=13
\]

です。

復号は、

\[
13^{27}\bmod55=7
\]

です。

手計算では、

\[
13^2\equiv4,
\quad13^4\equiv16,
\quad13^8\equiv36,
\quad13^{16}\equiv31\pmod{55}
\]

なので、

\[
13^{27}=13^{16}13^8 13^2 13
\equiv31\times36\times4\times13
\equiv7\pmod{55}
\]

となります。

### RSAが動く理由

(ed=81=1+2\times40) です。

メッセージ (m) が (n) と互いに素なら、Eulerの定理から、

\[
m^{\varphi(n)}\equiv1\pmod n
\]

です。

したがって、

\[
m^{ed}=m^{1+2\varphi(n)}
\equiv m\times1^2
\equiv m\pmod n
\]

となります。

実際のRSAの正しさは、(p) と (q) を法とする議論を組み合わせて、互いに素でない場合も含む形で説明します。
初心者の段階では、まず「指数を \(\varphi(n)\) だけずらしても余りが保たれる」という構造を押さえてください。

### 玩具例と実運用の違い

玩具例の (p=5,q=11) は、素因数分解が一瞬でできます。
このため、秘密鍵を知らなくても (n=55) から (p,q) を見つけられます。

実運用では、十分に大きく、適切に生成された素数を使います。
さらに、同じメッセージをそのまま (m^e\bmod n) にする「教科書的RSA」は、決定的で構造が漏れるため安全ではありません。

実運用では、用途に合う標準化されたパディング、鍵生成、署名方式、乱数を暗号ライブラリに任せます。

RSAは暗号化だけでなく、メッセージのハッシュ値に署名する公開鍵署名にも使われます。
署名では「誰でも公開鍵で検証できるが、秘密鍵を持つ者だけが作れる」という性質を使います。

## 9.8 数学的説明を実装へ落とす

### 擬似コード

```text
function gcd(a, b):
    while b != 0:
        a, b = b, a mod b
    return abs(a)

function modular_power(base, exponent, modulus):
    result = 1
    base = base mod modulus
    while exponent > 0:
        if exponent is odd:
            result = (result × base) mod modulus
        base = (base × base) mod modulus
        exponent = floor(exponent / 2)
    return result

function factorize(n):
    factors = empty map
    divisor = 2
    while divisor × divisor <= n:
        while n mod divisor == 0:
            factors[divisor] += 1
            n = n / divisor
        divisor += 1
    if n > 1:
        factors[n] += 1
    return factors
```

`modular_power` は、指数を半分ずつにするので、素朴に掛け続けるより高速です。
時間計算量は (O(\log e)) です。

### Python

```python
from math import gcd


def lcm(a: int, b: int) -> int:
    if a == 0 or b == 0:
        return 0
    return abs(a // gcd(a, b) * b)


def factorize(n: int) -> dict[int, int]:
    if n < 2:
        return {}

    factors: dict[int, int] = {}
    divisor = 2
    while divisor * divisor <= n:
        while n % divisor == 0:
            factors[divisor] = factors.get(divisor, 0) + 1
            n //= divisor
        divisor += 1
    if n > 1:
        factors[n] = factors.get(n, 0) + 1
    return factors


def euler_phi(n: int) -> int:
    if n < 1:
        raise ValueError("n must be positive")

    result = n
    for prime in factorize(n):
        result -= result // prime
    return result


def modular_power(base: int, exponent: int, modulus: int) -> int:
    if modulus <= 0 or exponent < 0:
        raise ValueError("modulus must be positive and exponent non-negative")

    result = 1 % modulus
    base %= modulus
    while exponent:
        if exponent & 1:
            result = result * base % modulus
        base = base * base % modulus
        exponent >>= 1
    return result


print(gcd(36, 24))                 # 12
print(lcm(24, 36))                 # 72
print(factorize(84))               # {2: 2, 3: 1, 7: 1}
print(euler_phi(12))               # 4
print(modular_power(2, 10, 1000))  # 24
```

ここでは、Pythonの組み込み `pow(base, exponent, modulus)` も同じ目的に使えます。
暗号用途では、アルゴリズムを自作するより、用途に合った実績あるライブラリを使います。

### 思考プロセス（再現可能な解法手順）と解答

**問題1**：1, 2, 3, 4, 6, 8, 12, 24です。

小さい約数 (d) を試し、(24\div d) が整数なら (d) と商を組にして列挙します。

**問題2**：(53=7\times7+4) なので、(53\bmod7=4)、(53\equiv4\pmod7) です。

**問題3**：

\[
84=30\times2+24
\]

\[
30=24\times1+6
\]

\[
24=6\times4+0
\]

最後の0でない余りが6なので、\(\gcd(84,30)=6\) です。

**問題4**：

\[
360=2\times180=2^2\times90=2^3\times45=2^3\times3^2\times5
\]

小さい素数から割り、商が1になるまで続けます。

**問題5**：

\[
24=2^3\times3,
\qquad90=2\times3^2\times5
\]

LCMは指数の大きい方を選ぶので、

\[
\operatorname{lcm}(24,90)=2^3\times3^2\times5=360
\]

GCDは (2\times3=6) です。

\[
6\times360=2160=24\times90
\]

で検算できます。

**問題6**：7と26は互いに素です。
7の倍数を26で割った余りを調べると、(7\times15=105\equiv1\pmod{26}) です。
よって逆元は15です。

**問題7**：

\[
n=3\times11=33,
\qquad\varphi(n)=2\times10=20
\]

(e=3) の逆元は、(3\times7=21\equiv1\pmod{20}) なので (d=7) です。

公開鍵は ((33,3))、秘密鍵は ((33,7)) です。

\[
c=4^3\bmod33=64\bmod33=31
\]

\[
31^7\bmod33=4
\]

となります。
復号できることを確認するのが手順の最後です。

**問題8**：

\[
10\bmod7=3,
17\bmod7=3,
24\bmod7=3,
8\bmod7=1
\]

10, 17, 24がバケット3で衝突します。

ハッシュ表では衝突を解決して同じ位置に複数のキーを置けます。
暗号学的ハッシュでは、衝突を意図的に作ることが難しいこと、入力から元の値を戻しにくいことなど、別の性質を要求します。
したがって、単純な剰余ハッシュの衝突は、暗号学的ハッシュの安全性を直接判定しません。
