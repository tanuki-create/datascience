# Part 5 数え上げ・組合せ論

この章では、候補を一つずつ列挙せずに、何通りあるかを数える。

公式より先に、一つの結果の作り方、順番、再利用、場合の重なりを確認する。

## 1. 直感

### 1.1 段階を続けるか、場合を分けるか

シャツ3種類とズボン2種類から一着を作るなら、シャツを選んだ後にズボンを選ぶので3 × 2 = 6通りである。

赤または青のペンを一つ選ぶなら、重ならない場合を分けるので1 + 1 = 2通りである。

数え上げの最初の問いは、選択が続くのか、どちらか一方のケースなのかである。

### 1.2 順番と再利用

A、B、Cから代表と副代表を決めるなら、Aを代表、Bを副代表と、Bを代表、Aを副代表は別の結果である。

委員を2人選ぶだけなら、これらは同じ集合を表す。

同じ数字を再び使える暗証列と、カードを一度しか使えない並べ方も区別する。

### 1.3 公式は重複を直す

3人から2人を順番つきで選ぶとABとBAが現れる。

委員の組ではこの二つを同じ結果とみなすので、順列を2!で割る。

公式は、何を何回数えたかを修正した結果である。

## 2. 正式定義

### 2.1 加法原理

互いに重ならない場合Aがa通り、場合Bがb通りなら、AまたはBはa+b通りである。

重なる場合は共通部分を補正する。

### 2.2 乗法原理

一つの結果を第1段階、第2段階へ分け、各結果が段階列に一意に対応するなら、各段階の選択数を掛ける。

第1段階a通り、第2段階b通りなら、全体はa×b通りである。

後の選択数が前の選択に依存する場合は、経路ごとの積を足す。

### 2.3 順列

異なるn個からr個を選び、順番をつける方法を順列という。

    P(n,r) = n × (n−1) × … × (n−r+1)
           = n! / (n−r)!

最初の位置n通り、次の位置n−1通りと段階的に選ぶためである。

### 2.4 組合せと二項係数

異なるn個から順番を区別せずr個を選ぶ方法を組合せという。

    C(n,r) = P(n,r) / r!
           = n! / (r! × (n−r)!)

一つのr個の組がr!通りの順列として数えられるので、r!で割る。

ここではn≥0、0≤r≤nを基本の定義域とし、計算関数では範囲外のC(n,r)を0として扱う。

### 2.5 重複を許す選び方

n種類から長さrの列を作り、各位置で再利用できるなら、nのr乗通りである。

順番を区別せず、n種類（n≥1）から合計r個（r≥0）を重複して選ぶなら、C(n+r−1,r)通りである。

これは、r個の印とn−1本の仕切りを並べる「印と仕切り」の数え方である。

### 2.6 パスカルの三角形

パスカルの三角形は、両端が1、内部が左上と右上の和になる。

    C(n,r) = C(n−1,r−1) + C(n−1,r)

特定の対象を選ぶ場合と選ばない場合に分けた式であり、基本の証明範囲はn≥1、0≤r≤nである。

### 2.7 二項定理

二項定理は、二つの項の和のn乗を展開する。

    (x+y)^n = Σ[k=0..n] C(n,k) × x^(n−k) × y^k

n個の括弧からyを選ぶ位置をk個決めるため、係数がC(n,k)になる。

### 2.8 鳩の巣原理

n個の箱にn+1個以上の物を入れると、少なくとも一つの箱に2個以上入る。

各箱に高々1個なら、入る物は最大n個だからである。

一般に、m個の箱へmk+1個を入れると、ある箱にk+1個以上入る。

### 2.9 包除原理

    |A∪B| = |A| + |B| − |A∩B|

AとBを足すと共通部分を2回数えるため、1回引く。

3集合では、2集合ずつの共通部分を引き、3集合すべての共通部分を足し戻す。

## 3. 最小例

### 3.1 加法と乗法

午前の講義2種類と午後の演習3種類から一つずつ選ぶなら、2×3=6通りである。

講義だけ、または演習だけを一つ選ぶなら、2+3=5通りである。

### 3.2 順列と組合せ

A、B、Cから2人を発表順つきで選ぶと、AB、AC、BA、BC、CA、CBの6通りである。

委員の集合を選ぶだけなら、AB、AC、BCの3通りである。

P(3,2)=6、C(3,2)=3となる。

### 3.3 重複を許す選択

赤、青、緑から2桁の列を作ると、再利用ありなら3×3=9通りである。

順番なしで色を合計2個選ぶなら、C(3+2−1,2)=C(4,2)=6通りである。

## 5. 手計算

### 5.1 役職を決める

4人から会長と書記を決める。

会長4通りの後、書記3通りなので4×3=12通りである。

役職が違うのでABとBAは別である。

### 5.2 委員を選ぶ

同じ4人から役職なしの委員2人を選ぶ。

順番つきの12通りは、各組を2!回数えている。

    C(4,2) = 12 / 2 = 6

### 5.3 包除原理

1から20までの2の倍数は10個、3の倍数は6個、6の倍数は3個である。

よって2または3の倍数は10+6−3=13個である。

### 5.4 二項定理の係数

(x+y)³のxy²を考える。

3個の括弧からyを選ぶ2個の位置を決めるので、係数はC(3,2)=3である。

    (x+y)³ = x³ + 3x²y + 3xy² + y³

## 6. 誤解

### 6.1 選ぶ問題はいつも組合せではない

役割や位置が違えば順列、集合だけなら組合せである。

### 6.2 重複には二つの意味がある

同じ種類を再利用できることと、同じ結果を二重に数えることは別である。

### 6.3 場合分けしたら必ず足せるわけではない

「または」を見たら、場合が排反か、共通部分を引く必要があるかを確認する。

### 6.4 nのr乗と組合せは同じではない

nのr乗は再利用可能な位置つきの列、C(n,r)は通常、異なる対象から選ぶ順番なしの集合である。

### 6.5 0個の選び方は1通りである

空の選び方を1通りと数えると、C(n,0)=1と0!=1が自然に保たれる。

## 7. 証明段階

### 7.1 加法原理と乗法原理

1. 全結果を重ならない場合へ分ける。
2. 各場合を数える。
3. 排反な場合は足す。
4. 一意な段階列で表せるなら、段階の数を掛ける。

一意性が漏れと二重計数を防ぐ。

### 7.2 組合せの公式

1. 順番つきではP(n,r)通りある。
2. 同じr個の組はr!通りの並べ方を持つ。
3. 組合せではそれらを一つとみなす。
4. よってP(n,r)をr!で割る。

### 7.3 パスカルの恒等式

1. 特定の対象Xに注目する。
2. Xを選ぶ場合は残りからr−1個を選ぶ。
3. Xを選ばない場合は残りからr個を選ぶ。
4. 二つは排反で、全ての組を覆う。
5. C(n,r)=C(n−1,r−1)+C(n−1,r)となる。

### 7.4 鳩の巣原理

各箱に高々1個しか入らないと仮定すると、m箱には最大m個しか入らない。

mk+1個の場合、各箱に高々k個なら最大mk個なので矛盾する。

### 7.5 包除原理

AとBを足すと共通部分だけが2回現れる。

その1回分を引くと、各要素がちょうど1回になる。

3集合では、3集合共通部分を引きすぎるため最後に足し戻す。

## 8. CS応用

### 8.1 検索空間

英小文字26種類で長さrの再利用可能なパスワードを作ると、候補は26のr乗個である。

長さを1増やすと候補が26倍になる。

### 8.2 テストケース

入力項目が3種類と4種類なら全組合せは12ケースである。

項目を増やしたときのケース数を乗法原理で見積もり、全組合せテストの実行可能性を判断する。

### 8.3 特徴選択

n個の特徴を選ぶか選ばないかで、部分集合は2のn乗通りである。

ちょうどr個を選ぶならC(n,r)通りである。

### 8.4 ハッシュ衝突と鳩の巣

出力がm種類しかないハッシュ値へ異なるキーをm+1個入れると、衝突は必ず起こる。

これはハッシュ関数の品質以前に、出力の種類数が有限であるためである。

### 8.5 条件付き集計と包除

「条件Aまたは条件B」の件数では、両方を満たす文書を二重に数えないよう共通部分を引く。

## 9. 数学的説明

### 9.1 集合の直積

集合Aから一つ、集合Bから一つを選ぶ順序つき組の集合をA×Bと書く。

有限集合では|A×B|=|A|×|B|であり、これが乗法原理である。

排反な集合では|A∪B|=|A|+|B|であり、これが加法原理である。

### 9.2 階乗と対称性

n!はn個すべてを並べる方法の数である。

組合せでは同じ集合のr!個の並べ方を同一視する。

### 9.3 重複組合せと仕切り

3種類から合計4個を選ぶとき、個数x1、x2、x3はx1+x2+x3=4、xi≥0を満たす。

4個の印と2本の仕切りを並べるので、6位置から印の位置を選ぶC(6,4)=15通りである。

### 9.4 二項係数の対称性

C(n,r)=C(n,n−r)である。

r個を選ぶ代わりに、選ばないn−r個を決めても同じ結果だからである。

### 9.5 計算量の条件

階乗からC(n,r)を計算すると、固定長整数モデルで時間O(n)である。

rとn−rの小さい方を使う積の計算なら、時間O(min(r,n−r))、追加空間O(1)である。

任意精度整数では桁数が増えるため、整数演算のビットコストも別に考える。

## 10. 擬似コード

### 10.1 組合せ

    function combination(n, r):
        if r < 0 or r > n:
            return 0
        r = min(r, n-r)
        answer = 1
        for i = 1 to r:
            answer = answer × (n-r+i) / i
        return answer

固定長整数モデルでは最悪時間O(min(r,n−r))、空間O(1)である。

### 10.2 包除原理

    function union_count(A, B):
        return size(A) + size(B) − size(intersection(A, B))

ハッシュ集合の要素数をNとすると、平均時間はO(N)、極端な衝突時の最悪時間は実装によってO(N²)である。

## 11. Python

    def combination(n: int, r: int) -> int:
        if r < 0 or r > n:
            return 0
        r = min(r, n - r)
        answer = 1
        for i in range(1, r + 1):
            answer = answer * (n - r + i) // i
        return answer

    def repeated_combination(n: int, r: int) -> int:
        if n < 0 or r < 0:
            return 0
        if r == 0:
            return 1
        if n == 0:
            return 0
        return combination(n + r - 1, r)

    def union_count(first: set[int], second: set[int]) -> int:
        return len(first) + len(second) - len(first & second)

    print(combination(4, 2))              # 6
    print(repeated_combination(3, 2))     # 6
    print(union_count({1, 2, 3}, {3, 4})) # 4

Pythonの標準ライブラリにはmath.combもあるが、自作関数は数え方と計算量を確認するために使う。

重複組合せの式はn≥1を前提にし、関数ではn=0の空選択だけを例外的に1通りとして扱っている。

## 13. 思考プロセス付き解答

ここでは、内部の独白ではなく、検証できる解法の筋道を示す。

### 問1の解答

二つの段階なので、4×3=12通りである。

### 問2の解答

代表5通りの後、副代表4通りなので20通りである。

役割なしでは同じ2人を2!回数えるため、20÷2=10通りである。

### 問3の解答

先頭0可なら各位置4通りで4³=64通りである。

先頭0不可なら先頭3通り、残り各4通りなので3×4²=48通りである。

### 問4の解答

4の倍数7個、6の倍数5個、共通する12の倍数2個なので、4または6は7+5−2=10個である。

そこから12の倍数2個を除き、8個である。

### 問5の解答

順番なしの重複選択なので、C(4+5−1,5)=C(8,5)=56通りである。

### 問6の解答

5個の括弧からyを選ぶ3個の位置を決める。

C(5,3)=10通りなので係数は10である。

### 問7の解答

鳩を13人、巣を12か月とする。

各月に高々1人なら最大12人しか入らないため、13人あることと矛盾する。

よって、少なくとも一つの月に2人以上いる。

## 14. 章間のつながり

集合と論理で学んだ場合分けを個数へ適用したものが数え上げである。

次章の再帰では、問題を小さい同型問題へ分けて答えを結合する。

パスカルの恒等式は組合せの数え上げであると同時に、二つの小問題へ分ける漸化式でもある。

再帰木の枝数を数えるときは乗法原理、各段の仕事を足すときは加法原理が現れる。
