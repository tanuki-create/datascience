# Part 1　論理

## 学習目標

- 命題の真偽を区別し、論理演算を真理値表で計算できる。
- 「PならばQ」の意味を、必要条件と十分条件の言葉で説明できる。
- 述語と量化記号を読み、量化記号を否定できる。
- 条件式、`boolean`、`assert` と数学論理の対応を説明できる。

## 直感

論理は、文章の印象ではなく、条件が成立しているかを機械的に判定するための言語です。

たとえば「パスワードが正しく、かつアカウントが有効ならログインを許可する」という処理では、二つの条件の両方が必要です。

プログラムはこの条件を真か偽かに変換し、分岐を選びます。

数学では、真または偽のどちらかを持つ文を**命題**と呼びます。

「今日は雨です」は、対象となる日が決まれば命題になります。

「窓を閉めてください」は真偽を判定する文ではないため、命題ではありません。

## 正式な定義

### 命題と真偽値

**命題**とは、真（`True`）または偽（`False`）のいずれか一つに決まる宣言文です。

命題を表す変数には通常 `P`、`Q`、`R` を使います。

### 基本演算

| 記号 | 読み方 | 真になる条件 |
|---|---|---|
| `¬P` | Pでない | Pが偽 |
| `P ∧ Q` | PかつQ | PとQがともに真 |
| `P ∨ Q` | PまたはQ | 少なくとも一方が真 |
| `P ⊕ Q` | PまたはQの一方だけ | 真偽が異なる |
| `P → Q` | PならばQ | Pが真なのにQが偽、という場合以外 |
| `P ↔ Q` | PとQは同値 | PとQの真偽が同じ |

「または」は数学やプログラムでは通常、両方とも真である場合も含みます。

### 含意の真理値表

含意 `P→Q` が偽になるのは、Pが真でQが偽の一行だけです。

| P | Q | `P→Q` |
|---|---|---|
| 偽 | 偽 | 真 |
| 偽 | 真 | 真 |
| 真 | 偽 | 偽 |
| 真 | 真 | 真 |

これは日常語の約束と少し違って見えます。

数学の含意は「Pが成立した場合にQも成立する」という保証を表し、Pが成立しない場合のQを約束しません。

したがって `P→Q` は `¬P∨Q` と論理的に同値です。

### 必要条件と十分条件

`P→Q` のとき、PはQの**十分条件**です。

Pが起きればQが必ず起きるからです。

QはPの**必要条件**です。

Pが起きるにはQが必要だからです。

`P↔Q` なら、PはQの必要十分条件です。

### 述語と量化

変数を含む文 `P(x)` を**述語**と呼びます。

対象が動く範囲を**定義域**または**論議領域**と呼び、`D` で表します。
`∀x∈D, P(x)` は「定義域DのすべてのxについてP(x)が真」を表します。

`∃x∈D, P(x)` は「定義域Dの中に、P(x)を真にするxが少なくとも一つ存在する」を表します。

量化記号を否定するときは、全称と存在を入れ替えます。

```text
¬(∀x∈D, P(x))  ↔  ∃x∈D, ¬P(x)
¬(∃x∈D, P(x))  ↔  ∀x∈D, ¬P(x)
```

## 最小の具体例

`P` を「入力値nは偶数」、`Q` を「nを2で割った余りは0」とします。

整数の範囲では `P↔Q` が成立します。

一方、「nは4の倍数」から「nは偶数」は導けますが、逆は導けません。

したがって「4の倍数」は「偶数」の十分条件であり、「偶数」は「4の倍数」の必要条件です。

## 「PならばQ」の読み方

日常語の「ならば」は、時間の順番や因果関係を含むことがあります。

数学の `P→Q` は、因果関係やPが実際に起きたことを主張していません。

「4の倍数なら偶数」は、4の倍数でない数について何も言いません。

たとえば `n=3` ではPは偽です。

このとき `P→Q` は真と定義されますが、「3は偶数だ」と言っているわけではありません。

「契約の条件Pを満たしたのに、結果Qが起きなかった」ときだけ約束が破られると考えると、真理値表を理解しやすくなります。

## ASCII図解

ド・モルガンの法則を真理値表で確認します。

```text
¬(P ∧ Q)  ↔  ¬P ∨ ¬Q
```

```text
P → Q の判定

P = 真 ───────────────→ Qを調べる
                            │
                            ├─ Q = 真  → 含意は真
                            └─ Q = 偽  → 含意は偽

P = 偽 ── 前件が成立していない ──→ 含意は真
```

必要条件と十分条件の向きは、矢印の左右で確認する。

```text
P  ─────────→  Q
│              │
└─ PはQの      └─ QはPの
   十分条件       必要条件
```

| P | Q | `P∧Q` | `¬(P∧Q)` | `¬P` | `¬Q` | `¬P∨¬Q` |
|---|---|---:|---:|---:|---:|---:|
| 偽 | 偽 | 偽 | 真 | 真 | 真 | 真 |
| 偽 | 真 | 偽 | 真 | 真 | 偽 | 真 |
| 真 | 偽 | 偽 | 真 | 偽 | 真 | 真 |
| 真 | 真 | 真 | 偽 | 偽 | 偽 | 偽 |

左辺と右辺の列がすべて一致するため、二つの式は論理的に同値です。

これは「PかつQではない」と「Pでない、またはQでない」が同じ条件を表すことを示します。

## 途中式を省略しない手計算

### 含意の真偽を計算する

`P=True`、`Q=False` のときに `P→Q` を計算する。

```text
P→Q
⇔ ¬P∨Q
⇔ False∨False
⇔ False
```

含意は前件が真で後件が偽のときだけ偽なので、この組合せでは偽である。

### 量化記号の否定を計算する

「すべての整数 `x` について `x²≥0`」を否定する。

```text
¬(∀x∈Z, x²≥0)
⇔ ∃x∈Z, ¬(x²≥0)       全称を存在へ交換
⇔ ∃x∈Z, x²<0          不等式を否定
```

実数の二乗は0以上なので、最後の命題を真にする整数は存在しない。
したがって元の全称命題は真であり、その否定は偽である。

### 必要条件と十分条件を手計算で確認する

Pを「`n` は4の倍数」、Qを「`n` は偶数」とする。

```text
P: n=4k  （kは整数）
n=4k
 =2(2k)
```

`2k` は整数なので、PならばQである。
よってPはQの十分条件、QはPの必要条件である。

逆向きが成り立たないことは、`n=2` を代入して確認できる。

```text
n=2 は偶数なのでQは真
2=4k を満たす整数kはないのでPは偽
Q→P は 真→偽 となり偽
```

## よくある誤解

- `P∨Q` は「どちらか一方だけ」とは限りません。
- `P→Q` を `Q→P` に入れ替えることはできません。
- `P→Q` から `¬P→¬Q` は導けません。
- 含意を証明するとき、Pが偽の例を調べるだけでは十分ではありません。
- 量化された文では、対象となる集合（定義域）を省略すると意味が変わります。

反例を一つ挙げると、偶数 `P` なら4の倍数 `Q` という含意は偽です。

`n=2` ではPが真、Qが偽になるからです。

## 証明

命題「整数nが4の倍数なら、nは偶数である」を証明します。

### 何を示すか

任意の整数nについて、`4|n` なら `2|n` を示します。

### 使う定義・定理

`4|n` とは、ある整数kを使って `n=4k` と書けることです。

### 方法候補

前提を直接式に置けるので、直接証明が自然です。

対偶を使う必要も、場合分けをする必要もありません。

### 骨格

1. `n=4k` と置く。
2. `n=2(2k)` と変形する。
3. `2k` は整数なので、nは偶数である。

### 完全な証明

`n` を4の倍数とする。

整除の定義より、ある整数kが存在して `n=4k` と書ける。

すると `n=4k=2(2k)` である。

`2k` は整数なので、整除の定義よりnは2の倍数、つまり偶数である。

## プログラミング・アルゴリズム・DB等との関係

数学の `∧`、`∨`、`¬` は、多くの言語の `and`、`or`、`not` に対応します。

```python
def can_login(password_ok: bool, account_active: bool) -> bool:
    return password_ok and account_active

assert can_login(True, True) is True
assert can_login(True, False) is False
```

`if` は条件が真のときに処理を選びます。

`assert` は、ある条件が真であるべきだという仕様を実行時に確認します。

ただし、プログラムの短絡評価では、数学の真理値表と違って右側を評価しない場合があります。

この違いは、式の真偽と評価手順を区別する例です。

アルゴリズムの仕様は、「入力が前提条件を満たすなら、出力が事後条件を満たす」という含意で書ける。
ループでは、各反復の前後で真のまま保たれるループ不変条件を置き、終了時に結論を導く。

データベースの `WHERE` も論理式である。

```sql
WHERE is_member = TRUE
  AND (role = 'admin' OR role = 'owner')
```

これは「会員であり、かつ管理者または所有者」という命題を表す。
ただしSQLの `NULL` は真偽に加えて不明を生むため、二値論理の真理値表をそのまま適用してはいけない。
`NULL` の有無を判定するときは `IS NULL` や `IS NOT NULL` を使う。

## 数学的説明 → 擬似コード → Python

### 条件を満たすときだけ許可する

数学的説明では、

```text
許可 ⇔ 年齢が18以上 ∧ 会員である ∧ 支払い済みである
```

と書く。

擬似コードでは次のようになる。

```text
入力 age, is_member, has_paid
if age >= 18 かつ is_member かつ has_paid ならば
    Trueを返す
else
    Falseを返す
```

Pythonでは、比較と `and` を対応させる。

```python
def can_purchase(age, is_member, has_paid):
    return age >= 18 and is_member and has_paid


print(can_purchase(20, True, True))
print(can_purchase(20, True, False))
print(can_purchase(17, True, True))
```

出力は `True`、`False`、`False` になる。

### 含意を擬似コードとPythonへ変換する

数学では `P→Q` は `¬P∨Q` と同値である。

```text
入力 P, Q
if P が偽 または Q が真 ならば
    Trueを返す
else
    Falseを返す
```

```python
def implies(p, q):
    return (not p) or q


for p in (False, True):
    for q in (False, True):
        print(p, q, implies(p, q))
```

`P=True` かつ `Q=False` の組だけが `False` になる。

## 演習問題

### ★ 基本

1. 「7は素数である」は命題ですか。
2. `P=True`、`Q=False` のとき、`¬P`、`P∧Q`、`P∨Q`、`P→Q` を求めてください。

### ★★ 標準

3. 「nが6の倍数ならnは3の倍数」を、必要条件と十分条件の言葉で説明してください。
4. `¬(P∨Q)` と同値な式を書いてください。

### ★★★ 応用

5. `∀x∈Z, x^2≥0` の否定を書いてください。
6. 「すべてのユーザーが有効なメールアドレスを持つ」の否定を、自然言語と量化記号で書いてください。

### ★★★★ 発展

7. `P→Q` と `¬Q→¬P` が同値であることを真理値表で確認してください。

## 思考プロセス付き解答

1. 真偽が決まる宣言文なので命題です。
2. `¬P=False`、`P∧Q=False`、`P∨Q=True`、`P→Q=False` です。
   含意は前件が真で後件が偽のときだけ偽です。
3. `n` が6の倍数であることが十分条件、nが3の倍数であることが必要条件です。
   逆向きは、3の倍数でも6の倍数とは限らないため成立しません。
4. ド・モルガンの法則から `¬P∧¬Q` です。
5. 「ある整数xが存在して `x^2<0`」です。
   実際にはそのような整数は存在しないため、元の全称命題は真です。
6. 「有効なメールアドレスを持たないユーザーが少なくとも一人存在する」です。
   `¬(∀u∈Users, Valid(u)) ↔ ∃u∈Users, ¬Valid(u)` です。
7. まず `P,Q` の4通りを並べ、左辺と右辺を別列で計算します。
   4行すべて一致すれば同値です。

   | P | Q | `P→Q` | `¬Q` | `¬P` | `¬Q→¬P` |
   |---|---|---:|---:|---:|---:|
   | 偽 | 偽 | 真 | 真 | 真 | 真 |
   | 偽 | 真 | 真 | 偽 | 真 | 真 |
   | 真 | 偽 | 偽 | 真 | 偽 | 偽 |
   | 真 | 真 | 真 | 偽 | 偽 | 真 |

   `P→Q` と `¬Q→¬P` の列が一致するため、二つは同値です。

## この章で学んだこと

論理は、条件の意味を真偽値として固定し、複合条件を機械的に扱うための言語です。

含意では、Pが真でQが偽になる場合だけを探すことが中心になります。
