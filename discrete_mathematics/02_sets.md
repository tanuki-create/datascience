# Part 2 集合

## この章の位置づけ

集合は、対象を「何が含まれているか」という所属関係で整理するための道具である。
配列、辞書、データベースの表、グラフの頂点集合、検索結果の集合は、すべて集合の考え方とつながっている。

この章は、前章の論理を独立した復習として説明する。
命題の真偽、`かつ`、`または`、`でない`を思い出せれば読み進められる。

## 学習目標

この章を終えると、次のことができる。

1. 集合、要素、所属、部分集合を定義に沿って説明できる。
2. 外延的記法と内包的記法で集合を表せる。
3. 共通部分、和集合、差集合、補集合、対称差を、図と論理式の両方で扱える。
4. 集合の濃度を有限集合で数え、和集合の濃度を重複に注意して求められる。
5. べき集合の意味を説明し、要素数が `2^n` になる理由を示せる。
6. 直積を順序付き組の集合として扱い、要素数と用途を説明できる。
7. 集合演算と論理演算、Pythonの `set`、DBの `JOIN` や `IN` を対応づけられる。
8. 集合に関する主張を、要素を一つ任意に取る直接証明や両包含で証明できる。

## 直感

### 集合は「条件で分けた箱」

集合は、対象の集まりを一つの箱として扱う考え方である。
箱の中に入っているかどうかだけが重要であり、同じ要素を二度入れても一つと数える。

```text
A = {りんご, みかん, ぶどう}

┌────────────── 集合 A ──────────────┐
│ りんご       みかん       ぶどう    │
└─────────────────────────────────────┘
```

順番も基本的には問題にしない。
`{1, 2, 3}` と `{3, 1, 2}` は同じ集合である。
これは、順番を持つリストやタプルとは異なる点である。

### 「要素である」は命題

「2は集合Aの要素である」は真か偽かが決まる命題である。
記号では `2 ∈ A` と書く。
「2はAの要素でない」は `2 ∉ A` と書く。

したがって、集合は論理と直結する。
「xがAとBの両方に入っている」は `x∈A ∧ x∈B` であり、「AまたはBに入っている」は `x∈A ∨ x∈B` である。

### 集合はデータの重複を消す

名簿に同じ名前が二度登場しても、「参加した人の集合」では一人として扱う。
集合の濃度は、重複を除いた要素の個数である。
出現回数まで区別したいなら、集合ではなくリストや多重集合、頻度辞書を使う。

## 正式な定義

### 集合、要素、所属

**集合**とは、対象を明確な所属条件によってまとめたものである。

集合 `A` に含まれる対象を**要素**または**元**という。
`x` が `A` の要素であることを `x ∈ A`、要素でないことを `x ∉ A` と書く。

要素を一つも持たない集合を**空集合**といい、`∅` と書く。
数学では文脈によって `{}` と書くこともあるが、この章では `∅` に統一する。
Pythonでは空集合は `set()` であり、`{}` は空の辞書なので注意する。

### 集合の表し方

**外延的記法**は、要素を列挙する。

```text
A = {1, 2, 3, 4}
```

**内包的記法**は、条件で要素を指定する。

```text
B = {x ∈ ℤ | x は偶数かつ 0 ≤ x ≤ 6}
```

この例では `B={0,2,4,6}` である。
縦棒 `|` は「〜を満たすもの」という意味で、「ただし」と読むこともある。

### 部分集合と真部分集合

**AがBの部分集合**であるとは、Aのすべての要素がBにも含まれることである。
記号では `A ⊆ B` と書く。

定義は次のとおりである。

```text
A ⊆ B  ⇔  ∀x, (x∈A → x∈B)
```

`A ⊆ B` かつ `A ≠ B` のとき、AをBの**真部分集合**といい、`A ⊂ B` と書く流儀がある。
ただし `⊂` を「部分集合」の意味で使う資料もあるため、この章では真部分集合を明示する。

空集合は、どの集合の部分集合でもある。
なぜなら、空集合には「Aに入っているがBに入っていない」要素が存在しないからである。

### 集合演算

集合 `A`、`B` に対する演算を定義する。

| 名称 | 記号 | 定義 |
|---|---|---|
| 共通部分 | `A ∩ B` | AとBの両方に属する要素の集合 |
| 和集合 | `A ∪ B` | AまたはBの少なくとも一方に属する要素の集合 |
| 差集合 | `A \ B` | Aに属し、Bには属さない要素の集合 |
| 補集合 | `Aᶜ` | 基準となる全体集合Uに属し、Aには属さない要素の集合 |
| 対称差 | `A △ B` | AまたはBの一方だけに属する要素の集合 |

要素 `x` の所属で書くと、

```text
x ∈ A∩B  ⇔  x∈A ∧ x∈B
x ∈ A∪B  ⇔  x∈A ∨ x∈B
x ∈ A\B  ⇔  x∈A ∧ x∉B
x ∈ Aᶜ   ⇔  x∈U ∧ x∉A
x ∈ A△B  ⇔  (x∈A) ⊕ (x∈B)
```

補集合は全体集合 `U` を指定しないと定まらない。
「自然数の集合の補集合」と言っても、全体集合を整数にするか実数にするかで結果が変わる。

### 集合の濃度

有限集合 `A` の**濃度**または**要素数**を `|A|` と書く。
重複は一度しか数えない。

二つの有限集合が同じ濃度を持つとは、要素を一対一に対応させる**全単射**が存在することである。
ここで全単射とは、Aの各要素にBのちょうど一つの要素を対応させ、Bの各要素も漏れなくちょうど一度対応させる対応である。
「要素を数える」ことは、要素を `1,2,3,...` と重ならずに対応させることだと考えられる。

### べき集合

集合 `A` のすべての部分集合を要素とする集合を、Aの**べき集合**といい、`𝒫(A)` または `P(A)` と書く。

```text
𝒫(A) = {X | X ⊆ A}
```

空集合 `∅` とA自身は必ず `𝒫(A)` に含まれる。
`A={a,b}` なら、

```text
𝒫(A) = {∅, {a}, {b}, {a,b}}
```

要素が `n` 個の有限集合の各要素には、「部分集合に入れる」「入れない」の2択がある。
したがって、`|𝒫(A)|=2^n` である。

### 直積

集合 `A` と `B` の**直積**は、Aから一つ、Bから一つを選び、順番を保った組をすべて集めた集合である。

```text
A × B = {(a,b) | a∈A かつ b∈B}
```

`(a,b)` は**順序付き組**であり、一般には `(a,b) ≠ (b,a)` である。
`A` の要素数が `m`、`B` の要素数が `n` なら、各 `a` に対してBからn通り選べるので、

```text
|A×B| = |A|×|B| = mn
```

となる。

## 最小の具体例

```text
A = {1, 2, 3}
B = {3, 4}
```

所属を確認する。

```text
2 ∈ A       真
4 ∈ A       偽
3 ∈ A∩B     真
```

演算を計算する。

```text
A ∩ B = {3}
A ∪ B = {1, 2, 3, 4}
A \ B = {1, 2}
B \ A = {4}
```

直積は、Aから一つ、Bから一つを選ぶ。

```text
A×B = {(1,3), (1,4), (2,3), (2,4), (3,3), (3,4)}
```

よって、

```text
|A| = 3
|B| = 2
|A∩B| = 1
|A∪B| = 4
|A×B| = 3×2 = 6
```

```text

```

## 途中式を省略しない手計算

### 例1：重複を除いて和集合の濃度を求める

```text
A = {1, 2, 3, 4}
B = {3, 4, 5}
```

1. Aの要素を数える。

```text
|A| = 4
```

2. Bの要素を数える。

```text
|B| = 3
```

3. 共通する要素を取り出す。

```text
A∩B = {3,4}
|A∩B| = 2
```

4. `|A|+|B|` では、3と4を二回ずつ数えている。

```text
|A| + |B| = 4 + 3 = 7
二重に数えた個数 = |A∩B| = 2
```

5. 重複分を一回引く。

```text
|A∪B| = |A| + |B| - |A∩B|
       = 4 + 3 - 2
       = 7 - 2
       = 5
```

実際に `A∪B={1,2,3,4,5}` なので5個である。

### 例2：べき集合の要素を列挙する

```text
A = {a,b}
```

各要素について、部分集合に入れるか入れないかを選ぶ。

```text
aを入れない、bを入れない → ∅
aを入れる、 bを入れない → {a}
aを入れない、bを入れる  → {b}
aを入れる、 bを入れる   → {a,b}
```

よって、

```text
𝒫(A) = {∅, {a}, {b}, {a,b}}
|𝒫(A)| = 4
2^|A| = 2^2 = 4
```

`a` と `b` が要素であることと、`{a}` と `{b}` がべき集合の要素であることを区別する。
`a ∈ A` だが、`{a} ⊆ A` である。
この二つは記号も意味も違う。

### 例3：直積を列挙して濃度を確認する

```text
A = {0,1}
B = {赤,青,緑}
```

1. `a=0` の組を作る。

```text
(0,赤), (0,青), (0,緑)
```

2. `a=1` の組を作る。

```text
(1,赤), (1,青), (1,緑)
```

3. すべてを合わせる。

```text
A×B = {(0,赤),(0,青),(0,緑),(1,赤),(1,青),(1,緑)}
```

4. 要素数を掛け算で求める。

```text
|A| = 2
|B| = 3
|A×B| = 2×3 = 6
```

### 例4：集合演算の分配法則を要素で確認する

示したい式を、

```text
A ∩ (B ∪ C) = (A∩B) ∪ (A∩C)
```

とする。
任意の要素 `x` を一つ取る。

```text
x∈A∩(B∪C)
⇔ x∈A ∧ x∈(B∪C)                 共通部分の定義
⇔ x∈A ∧ (x∈B ∨ x∈C)             和集合の定義
⇔ (x∈A ∧ x∈B) ∨ (x∈A ∧ x∈C)     論理の分配法則
⇔ x∈(A∩B) ∨ x∈(A∩C)             共通部分の定義
⇔ x∈(A∩B)∪(A∩C)                 和集合の定義
```

任意の `x` について左右の所属が一致するため、二つの集合は等しい。

## よくある誤解

### `∈` と `⊆` を同じだと思う

`x∈A` は要素と集合の関係である。
`A⊆B` は集合と集合の関係である。

```text
a ∈ {a,b}       正しい
{a} ⊆ {a,b}     正しい
{a} ∈ {a,b}     この具体例では偽
```

最後が真になるには、集合 `{a,b}` の中に要素として `{a}` が実際に含まれていなければならない。

### 集合では順番や重複を数える

`{1,2,3}` と `{3,2,1}` は同じ集合である。
`{1,1,2}` は `{1,2}` と同じ集合である。
順番や重複を保存したいなら、リスト、タプル、多重集合を使う。

### 和集合の濃度を単純に足す

`|A∪B|=|A|+|B|` が成り立つのは、`A∩B=∅` のときだけである。
重複がある場合は `|A∩B|` を一度引く。

### 補集合に全体集合はいらない

`Aᶜ` は「どの世界の外側か」が必要である。
`U={1,2,3,4,5}` で `A={1,2}` なら `Aᶜ={3,4,5}` だが、`U={1,2,3}` なら `Aᶜ={3}` になる。

### 直積を和集合と混同する

`A∪B` は要素を一つずつ集める。
`A×B` はAとBから一つずつ選んだ順序付き組を作る。
前者の濃度は重複を調整し、後者の濃度は選択肢の積になる。

### べき集合の要素を数えるとき、A自身を忘れる

`∅` とA自身は必ずAの部分集合である。
`A={a,b}` のべき集合に `{a,b}` がない、という誤りが多い。

### Pythonの集合をそのまま数学の集合だと思う

Pythonの `set` はハッシュ可能な要素を扱い、要素の順序を意味として保持しない。
数学上の集合を実装する便利なモデルだが、無限集合や集合を要素にする集合など、すべてを直接表せるわけではない。

## 証明

### 何を示すか

集合の等式 `A=B` を示すには、同じ要素を持つことを示す。
最も基本的な方法は、任意の要素 `x` について、

```text
x∈A ⇔ x∈B
```

を示すことである。
集合の包含 `A⊆B` を示すなら、Aから任意に要素を一つ取り、それがBにも入ることを示す。

### 使う定義・定理

- 集合の等号：二つの集合の要素が完全に一致する。
- 部分集合：`A` のすべての要素が `B` にも属する。
- 共通部分：両方に属する要素の集合。
- 和集合：少なくとも一方に属する要素の集合。
- 差集合：前者に属し、後者に属さない要素の集合。
- 補集合：全体集合に属し、対象集合に属さない要素の集合。
- 論理のド・モルガン則：`¬(P∧Q)⇔¬P∨¬Q`、`¬(P∨Q)⇔¬P∧¬Q`。
- 包除原理：有限集合について `|A∪B|=|A|+|B|-|A∩B|`。

### 方法候補

| 主張の形 | 方法候補 |
|---|---|
| `A⊆B` | Aから任意の要素xを取って、x∈Bを示す |
| `A=B` | `A⊆B` と `B⊆A` の両方を示す、または所属の同値を示す |
| `x∉A` の存在 | 具体的な反例を構成 |
| 濃度の公式 | 重複の数え上げ、全単射、場合分け |
| べき集合の要素数 | 各要素の二択を数える |
| 演算の等式 | 任意のxについて所属条件を論理式に変換 |

### 骨格

集合の等式を要素で証明する骨格は次のとおりである。

```text
示したい命題：A = B
1. 任意の要素xを取る。
2. x∈Aを、演算の定義に従って論理式へ変換する。
3. 論理の同値変形を行う。
4. 変形後の式を集合Bの所属条件として読み直す。
5. x∈A ⇔ x∈B なので、A=B。
```

### 完全な証明：和集合の交換法則

**主張**：`A∪B = B∪A`。

**証明**：

1. 任意の対象 `x` を取る。
2. 和集合の定義により、

```text
x∈A∪B ⇔ x∈A ∨ x∈B
```

3. 論理和の交換法則により、

```text
x∈A ∨ x∈B ⇔ x∈B ∨ x∈A
```

4. 和集合の定義を逆向きに使う。

```text
x∈B ∨ x∈A ⇔ x∈B∪A
```

5. よって、任意の `x` について `x∈A∪B ⇔ x∈B∪A` である。
6. したがって、`A∪B=B∪A` である。□

### 完全な証明：べき集合の濃度

**主張**：要素数が `n` 個の有限集合 `A` について、`|𝒫(A)|=2^n`。

**証明**：

1. `A` の要素を `a1,a2,...,an` と並べる。
2. Aの部分集合Xを一つ作るとき、各要素 `ai` について、Xに入れるか入れないかの二択がある。
3. `a1` の選び方は2通りである。
4. `a1` の選び方を一つ固定すると、`a2` の選び方は2通りなので、ここまでで `2×2=2²` 通りである。
5. 同じ理由を `an` まで繰り返すと、

```text
2×2×...×2  （2をn回掛ける）
= 2^n
```

6. 各選択結果は、含めた要素の集合を一つだけ決める。
7. 異なる選択結果は、少なくとも一つの要素の所属が異なるため、異なる部分集合を決める。
8. よって、部分集合と二択列は一対一に対応する。
9. したがって、`|𝒫(A)|=2^n` である。□

### 完全な証明：直積の濃度

**主張**：有限集合 `A`,`B` について、`|A×B|=|A||B|`。

**証明**：

1. `|A|=m` とし、Aの要素を `a1,...,am` とする。
2. `|B|=n` とし、Bの要素を `b1,...,bn` とする。
3. 直積の定義により、`A×B` の要素は `(ai,bj)` の形である。
4. `a1` を第一成分に固定すると、第二成分はBから選ぶので、組はn個できる。

```text
(a1,b1), (a1,b2), ..., (a1,bn)  → n個
```

5. `a2`、...、`am` を第一成分に固定した場合も、それぞれn個できる。
6. 第一成分の選び方がm通りあり、各選び方にn通りの第二成分が対応する。
7. したがって、組の総数は、

```text
n+n+...+n  （nをm回足す）
= m×n
```

8. よって `|A×B|=mn=|A||B|` である。□

## プログラミング・アルゴリズム・DB等との関係

### Pythonの `set`

Pythonの集合は、重複を除いた要素の集まりである。

```python
participants = {"Aki", "Mio", "Ren", "Aki"}
print(participants)
print(len(participants))
```

`"Aki"` は二度書かれているが、集合の要素は一つであり、濃度は3になる。
表示順は集合の数学的な意味では重要でない。

### 集合演算とアルゴリズム

```python
frontend = {"Aki", "Mio", "Ren"}
backend = {"Mio", "Ren", "Sora"}

print(frontend & backend)  # 共通部分
print(frontend | backend)  # 和集合
print(frontend - backend)  # 差集合
print(frontend ^ backend)  # 対称差
```

ハッシュ表を使う実装では、要素の所属確認や追加が平均的に高速になる。
ただし計算量は要素の型、ハッシュ関数、実装、入力分布によって変わるので、数学上の集合の性質と実装上の性能を分けて考える。

### べき集合と組合せ探索

機能フラグの全組合せ、権限の全部分集合、選ぶ品目の全候補を列挙するとき、対象の集合のべき集合を探索している。
要素数nに対して候補が `2^n` 個になるため、nが少し増えるだけで全探索が急増する。
これはビットマスクによる部分集合列挙にも対応する。

### 直積と全探索

色の集合とサイズの集合から商品候補を作る処理は、二つの集合の直積である。
三つの選択肢を組み合わせるなら、`A×B×C` の要素数は `|A||B||C|` になる。
組合せが多いときは、制約で枝を切るバックトラッキングや動的計画法を検討する。

### データベースとの関係

リレーショナルデータベースでは、表を行の集合として見ると、集合の考え方が役立つ。

- `WHERE` による絞り込みは、条件を満たす行の部分集合を作る。
- `UNION` は重複を除く和集合に近い。
- `INTERSECT` は共通部分に近い。
- `EXCEPT` は差集合に近い。
- `CROSS JOIN` は直積に近い。
- `INNER JOIN` は共通するキーを使った対応関係の抽出である。

SQLの表は重複行を許すため、数学の集合と完全には同じでない。
SQLで重複を除くには `DISTINCT` が必要な場合があり、`NULL` は三値論理を導入する。
したがって、集合の直感を使いながら、SQL固有の重複と不明値の規則を確認する。

### グラフと機械学習

グラフでは、頂点の集合 `V` と辺の集合 `E` を使う。
推薦システムでは、ユーザー集合と商品集合の直積の部分集合を、評価や購入という関係として扱える。
データセットの訓練集合と検証集合を分けるときも、集合の共通部分が空であることを確認すると、データリークを発見しやすい。

## 数学的説明 → 擬似コード → Python

### 問題：二つの参加者集合から共通参加者を求める

数学的説明は次のとおりである。

```text
集合A = 午前の参加者
集合B = 午後の参加者
求める集合 = A∩B
```

要素 `x` が結果に入る条件は、`x∈A ∧ x∈B` である。

擬似コードを書く。

```text
入力 A, B
結果を空集合にする
for x を A の各要素について繰り返す
    if x が B の要素ならば
        x を結果に追加する
結果を返す
```

Pythonでは `&` が共通部分に対応する。

```python
def intersection(left, right):
    result = set()
    for value in left:
        if value in right:
            result.add(value)
    return result


morning = {"Aki", "Mio", "Ren"}
afternoon = {"Mio", "Ren", "Sora"}
print(intersection(morning, afternoon))
print(morning & afternoon)
```

二つの出力は同じ集合を表す。
この実装では、`right` が集合なので `value in right` を効率よく判定できる。

### 問題：部分集合を列挙する

数学的説明では、`A={a1,...,an}` の各要素を入れるか入れないかの二択を行う。
ビット列 `000` から `111` を対応させると、各ビットが所属を表す。

擬似コードは次のとおりである。

```text
入力 A = [a0, a1, ..., a(n-1)]
for mask を 0 から 2^n - 1 まで繰り返す
    部分集合を空にする
    for i を 0 から n-1 まで繰り返す
        if mask の i ビット目が1ならば
            A[i]を部分集合に追加する
    部分集合を出力する
```

Python標準機能だけで書く。

```python
def power_set(values):
    # 集合として扱うため、重複した入力は一つにまとめる。
    values = list(dict.fromkeys(values))
    result = []
    for mask in range(1 << len(values)):
        subset = set()
        for index, value in enumerate(values):
            if mask & (1 << index):
                subset.add(value)
        result.append(subset)
    return result


for subset in power_set(["a", "b", "c"]):
    print(subset)
```

`1 << n` は `2^n` をビット演算で表している。
結果の個数は `2^n` であり、入力が大きいと出力自体が巨大になる。

## 思考プロセス付き解答

ここでいう「思考プロセス」は、再現可能な解法の手順である。
集合では、まず要素か集合かを確認し、次に演算の定義を適用し、最後に重複と順序を確認する。

### 問1の解答

重複する `2` は集合では一度だけ数える。

```text
A = {1,2,3}
|A| = 3
2∈A = 真
4∈A = 偽
```

### 問2の解答

共通部分は両方にある要素、和集合は少なくとも一方にある要素、差集合は左にだけある要素を選ぶ。

```text
A∩B = {3}
A∪B = {1,2,3,4,5}
A\B = {1,2}
B\A = {4,5}
```

### 問3の解答

左辺の型を確認する。

```text
a は要素       → a∈A は真
{a} は集合     → {a}⊆A は、aがAに入るので真
{a}∈A          → Aの要素はa,bであり、{a}ではないので偽
A⊆A            → Aのすべての要素はA自身に入るので真
```

### 問4の解答

要素数は3なので、各要素の所属が二択である。

```text
|𝒫(A)| = 2^3 = 2×2×2 = 8
```

`{x,z}` はAの要素 `x`,`z` だけからなる集合であり、どちらもAに入っている。
したがって `{x,z}⊆A` であり、べき集合の定義から `{x,z}∈𝒫(A)` である。

### 問5の解答

第一成分を固定して、第二成分を全て組み合わせる。

```text
A×B = {(1,赤),(1,青),(1,緑),(2,赤),(2,青),(2,緑)}
|A×B| = |A||B| = 2×3 = 6
```

`B×A` には `(赤,1)` が入り、`(1,赤)` とは順番が違う。
したがって一般には同じ集合ではない。
この例でも、`(1,赤)∈A×B` だが `(1,赤)∉B×A` である。

### 問6の解答

部分集合の証明なので、左辺から任意の要素を取る。

1. `x∈A∩B` と仮定する。
2. 共通部分の定義より、`x∈A` かつ `x∈B` である。
3. 特に `x∈A` である。
4. 任意に選んだ `x` がAに入るので、`A∩B⊆A` である。□

### 問7の解答

集合の等式なので、任意の `x` について所属条件を変形する。

```text
x∈A∪(B∩C)
⇔ x∈A ∨ x∈(B∩C)                    和集合の定義
⇔ x∈A ∨ (x∈B ∧ x∈C)                共通部分の定義
⇔ (x∈A∨x∈B) ∧ (x∈A∨x∈C)            論理の分配法則
⇔ x∈(A∪B) ∧ x∈(A∪C)                和集合の定義
⇔ x∈(A∪B)∩(A∪C)                    共通部分の定義
```

任意の `x` で所属が同値なので、等式が成り立つ。

### 問8の解答

全要素は二つのリストを集合に変換して和集合を取る。
共通要素は共通部分を取る。
濃度は `len` で求める。

```python
def summarize_values(left, right):
    left_set = set(left)
    right_set = set(right)
    union = left_set | right_set
    common = left_set & right_set
    return len(union), common


count, common_values = summarize_values([1, 1, 2, 3], [2, 3, 3, 4])
print(count)          # 4
print(common_values)  # {2, 3}
```

入力を集合に変換することで、リスト内の重複を数学上の集合の重複として一度に除いている。
順序を残す必要がある仕様なら、この実装をそのまま使ってはいけない。

## この章で学んだこと

- 集合は要素の所属関係で対象をまとめる。
- `∈` は要素と集合、`⊆` は集合と集合の関係である。
- `∩`、`∪`、差集合、補集合、対称差は、要素の所属条件で定義される。
- 有限集合の濃度は重複を除いて数える。
- 和集合の濃度では共通部分を二重に数えた分だけ引く。
- 要素数nの集合のべき集合には `2^n` 個の部分集合がある。
- 直積は順序付き組の集合であり、濃度は要素数の積になる。
- 集合演算は論理演算に対応し、Pythonの `set`、組合せ探索、DB演算へつながる。

## 前章とのつながり

前章の論理では、「PかつQ」「PまたはQ」「Pでない」を学んだ。
集合では、要素 `x` の所属を命題として、

```text
x∈A∩B  ⇔  (x∈A)∧(x∈B)
x∈A∪B  ⇔  (x∈A)∨(x∈B)
x∈Aᶜ   ⇔  ¬(x∈A)
```

と書ける。
この対応により、論理のド・モルガン則や分配法則を集合の等式へ移せる。

## 次章とのつながり

次の章では、集合上の関係や写像を学ぶ準備として、直積の要素である順序付き組を使う。
「どの要素とどの要素を対応づけるか」は直積の部分集合として表せる。
また、全単射による濃度の比較は、写像を理解するための基礎になる。

## CSでの利用

集合は、重複除去、所属確認、アクセス権の合成、タグ検索、グラフ構造、テーブル演算、組合せ探索で使われる。
べき集合は、機能の有効無効、権限の組合せ、部分集合DPの状態数を見積もる手がかりになる。
直積は、候補の全組合せ、座標、キーの組、テストケース生成を理解するモデルになる。

データ処理では、「順序を気にしないか」「重複を残すか」「欠損値をどう扱うか」を最初に決める。
この仕様を曖昧にしたまま `set` や `UNION` を使うと、必要な重複や順序を失う。
