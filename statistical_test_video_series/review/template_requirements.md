# 統計検定短尺動画テンプレート要件・品質レビュー

## 前提

- 形式: 縦動画 1080x1920。
- 尺: 20〜25秒。1本1テーマに限定し、説明を増やして尺を延ばさない。
- 音声: 無音でも理解できる字幕・図解を必須にする。ナレーション前提の情報を画面外に置かない。
- 対象: 統計検定の初心者。厳密な証明ではなく、何を比べる検定か、どの場面で使うか、似た検定との違いを破綻なく伝える。
- 表記: 数式はASCIIベースでもよいが、画面上では `xbar`, `mu0`, `sqrt(n)` などの意味が図と対応するようにする。

## 各動画に必ず入れる6要素

| 要素 | 画面上の役割 | レビュー基準 |
| --- | --- | --- |
| 何を比較するか | 冒頭2〜4秒で比較対象を固定する | 「1群 vs 基準値」「独立2群の平均」「ペア差」「順位」「分布」「3群以上の平均」など、検定ごとに比較対象が混ざらない |
| 帰無仮説 | 判断の基準線を示す | `H0:` を使い、0差・基準値・分布同一などを一文で表示する |
| 使う場面 | 誤用を避ける | データ構造がわかる短い例を入れる。例だけで検定名を決めない |
| 前提条件 | 使える条件を示す | 独立性、正規性、対応の有無、群数、尺度、等分散などを検定ごとに必要最小限で出す |
| 一個下のレイヤー | 何を統計量に変換するかを見せる | 平均差、ペア差、順位、累積分布差、群間/群内のばらつきなど、統計量の材料を図で示す |
| 覚えるポイント | 最後2〜3秒の定着 | 「この検定は何と何を比べるか」を1文で再提示する |

## 推奨タイムライン

| 時間 | 内容 | 表示上の注意 |
| --- | --- | --- |
| 0.0〜2.5秒 | フック + 検定名 | 検定名は短縮名を大きく表示。正式名は小さくしすぎない |
| 2.5〜6.0秒 | 何を比較するか | 群ラベル、基準線、矢印を最初に確定する |
| 6.0〜9.5秒 | 帰無仮説 | `H0:` と比較対象を同じ画面に置く |
| 9.5〜13.5秒 | 使う場面 | 1例だけ。例が検定の条件を満たす図にする |
| 13.5〜17.5秒 | 前提条件 | 3項目以内。長文ではなく条件チップにする |
| 17.5〜22.0秒 | 一個下のレイヤー | 統計量の素材を図解し、式は補助にする |
| 22.0〜25.0秒 | 覚えるポイント | 1文で締める。次の検定の話を混ぜない |

## 画面設計要件

- セーフエリア: 上下左右80px以上を基本余白にし、字幕・群ラベル・軸ラベルを端に置かない。
- 最小文字サイズ: 本文字幕は48px以上、数式は56px以上、検定名は72px以上を目安にする。
- 数式: 1画面に1本まで。分母・添字・平方根が潰れる場合は式を2段に分ける。
- 図: 点群、平均バー、順位、累積分布、F比など、検定の「比較している量」が一目でわかるものを優先する。
- 色: 群A、群B、基準値、統計量の色を固定する。別の検定で統計量の色を再利用する場合も、ラベルで必ず区別する。
- 字幕: 1行15〜18文字程度、最大2行。画面内説明文で数式や群ラベルを隠さない。
- ラベル: `A群`, `B群`, `基準値`, `Before`, `After`, `順位`, `累積分布` は図の近くに置き、アニメーション中も見切れない。

## 検定別の設計注意

| 検定・統計量 | 比較するもの | 帰無仮説の表現 | 一個下のレイヤー | 混同防止 |
| --- | --- | --- | --- | --- |
| 1標本t検定 / t | 1群の平均と基準値 | 母平均は基準値と等しい | 平均差を標準誤差で割る | `1群 vs 基準値` を強調し、2群比較に見せない |
| 対応なし2標本t検定 / t | 独立した2群の平均 | 2群の母平均差は0 | 平均差を差の標準誤差で割る | 同じ人の前後を描かない。等分散型とWelchを混ぜない |
| 対応あり2標本t検定 / t | ペア内の差の平均 | ペア差の母平均は0 | 各ペアの差を作って1標本tにする | `A群 vs B群` ではなく `After - Before` を主役にする |
| Mann-Whitney U検定 / U | 独立2群の順位・分布位置 | 2群の分布に差がない | 値をまとめて順位化し、順位の偏りを見る | 「中央値検定」と言い切らない。平均差の検定にも見せない |
| Kolmogorov-Smirnov検定 / D | 2つの累積分布の形 | 2群は同じ分布から来た | 累積分布の最大縦差Dを見る | U検定の順位差と混ぜない。`D = 最大距離` を図で示す |
| 一元配置ANOVA / F | 3群以上の平均 | すべての群平均は等しい | 群間のばらつき / 群内のばらつき | t検定の多用に見せない。多重比較は「必要なら後で確認」程度に止める |

## ノンパラメトリック検定の表現ルール

- 「正規分布を強く仮定しない」「順位や分布の形を使う」と説明する。
- Mann-Whitney U検定を「中央値だけを比べる検定」と断定しない。分布の形が似ている条件では位置の差として解釈しやすい、という扱いにする。
- ノンパラメトリック = 前提条件なし、と言わない。独立性、対応関係、尺度、分布形の解釈条件は残る。
- `U` と `D` を混同しない。`U` は順位の偏り、`D` は累積分布の最大差。

## ANOVAの表現ルール

- 一元配置ANOVAは「3群以上の平均に差があるか」を見る検定として扱う。
- F統計量は「群間のばらつきが、群内のばらつきに比べて大きいか」と説明する。
- 「どの群とどの群が違うか」はANOVA本体では直接決まらない。短尺では「有意なら必要に応じて多重比較」までに止める。
- Tukey法などの名前を列挙しすぎない。初心者向け本編ではANOVAの主目的を薄めない。

## 品質レビュー観点

### 内容の正確性

- 比較対象が検定名と一致している。
- 帰無仮説が「差がない」「等しい」「同じ分布」など、検定ごとの基準を正しく示している。
- 前提条件が過剰でも不足でもない。特に独立2群と対応あり2群が入れ替わっていない。
- t統計量、U統計量、D統計量、F統計量の意味が混ざっていない。
- ノンパラメトリック検定を「中央値検定」と言い切りすぎていない。
- ANOVA後の多重比較に触れすぎず、主題がF検定から逸れていない。

### 視認性

- 数式が小さすぎない。スマホ表示で分母、添字、記号が読める。
- 群ラベルが見切れない。アニメーションの開始・終了フレームでも安全領域内にある。
- 字幕が図、数式、判定ラベルを隠していない。
- 色だけに依存せず、ラベルや形でも群・統計量を区別できる。
- 1画面に出す情報量が多すぎない。20〜25秒内で読み切れる。

### 初心者向けのわかりやすさ

- 最初に「何を比べる検定か」がわかる。
- 例は身近でも、条件が誤解されない。前後比較、独立2群、3群以上を図で明確に分ける。
- 一個下のレイヤーは計算手順ではなく、統計量が何から作られるかを示す。
- 覚えるポイントが検定の使い分けに直結している。
