# 04. データ選択

必要な行・列だけを取り出す章です。抽出の精度は、分析結果の正しさに直結します。

## `loc[]`

- 基本の説明: ラベル名で行・列を選択します。条件式による行抽出にもよく使います。
- 基本構文: `df.loc[行指定, 列指定]` / `series.loc[ラベル指定]`
- 主な引数/指定:
  - 行指定: 行ラベル、行ラベルのリスト、ラベルスライス、真偽値の条件式を指定します。
  - 列指定: 列名、列名のリスト、列名スライス、真偽値の条件式を指定します。
  - 条件式: `df["sales"] >= 100000` のような真偽値の `Series` を指定します。
  - 代入: `df.loc[条件, "列名"] = 値` の形で条件に合うセルを更新できます。
- 戻り値: 指定内容に応じて `DataFrame`、`Series`、スカラー値を返します。代入時は元の `DataFrame` を更新します。
- 実用での使用場面: 「東京店舗だけ」「売上が一定以上だけ」「特定列だけ」を取り出すときに使います。
- 使用例:

```python
tokyo = sales.loc[sales["store"] == "Tokyo", ["date", "product", "quantity"]]
print(tokyo)

high_sales = sales.loc[sales["sales"] >= 100000, :]
sales.loc[sales["sales"] < 0, "sales"] = 0
```

- よくある注意点:
  - `loc[]` のスライスはラベルベースで、終了ラベルも含みます。
  - 複数条件は `&` や `|` を使い、各条件を括弧で囲みます。`and` / `or` は使えません。
  - 抽出後の一部に代入すると警告や意図しない挙動になることがあります。条件代入は `df.loc[条件, 列] = 値` の形で書きます。
  - インデックスが整数の場合でも、`loc[]` は位置ではなくラベルとして解釈します。
- 関連メソッド: `iloc[]`, `at[]`, `query()`, `where()`, `mask()`, `isin()`
- インパクト: 条件と列指定を同時に書けるため、抽出処理が読みやすくなります。

## `iloc[]`

- 基本の説明: 行番号・列番号で選択します。0始まりの位置指定です。
- 基本構文: `df.iloc[行番号指定, 列番号指定]` / `series.iloc[位置指定]`
- 主な引数/指定:
  - 行番号指定: 整数位置、整数位置のリスト、スライス、真偽値配列を指定します。
  - 列番号指定: 整数位置、整数位置のリスト、スライスを指定します。
  - スライス: Python標準のスライスと同じく、終了位置は含みません。
- 戻り値: 指定内容に応じて `DataFrame`、`Series`、スカラー値を返します。代入も可能です。
- 実用での使用場面: 先頭からN行、特定位置の列、サンプル確認などに使います。
- 使用例:

```python
first_two_rows = sales.iloc[:2, :]
first_column = sales.iloc[:, 0]
cell = sales.iloc[0, 1]
subset = sales.iloc[[0, 2, 4], [0, 3]]
```

- よくある注意点:
  - `iloc[]` は位置ベースなので、終了位置は含みません。`0:3` は0, 1, 2行目です。
  - 列順が変わると意味が変わります。本番処理で業務的な列を指定する場合は `loc[]` の方が読みやすいことが多いです。
  - 範囲外の単一位置を指定するとエラーになります。一方、スライスは範囲外でも可能な範囲を返します。
  - 真偽値条件に列名を使う場合は、通常 `loc[]` の方が自然です。
- 関連メソッド: `loc[]`, `iat[]`, `head()`, `tail()`, `take()`
- インパクト: 列名が分からない段階でも位置で確認できます。ただし列順変更に弱いので、本番処理では `loc[]` の方が安全な場面が多いです。

## `at[]`

- 基本の説明: ラベルで単一セルを高速に取得・更新します。
- 基本構文: `df.at[行ラベル, 列名]` / `series.at[ラベル]`
- 主な引数/指定:
  - 行ラベル: インデックス上のラベルを指定します。
  - 列名: 取得・更新したい1列の列名を指定します。
  - 代入: `df.at[行ラベル, 列名] = 値` の形で単一セルを更新できます。
- 戻り値: 単一セルのスカラー値を返します。代入時は元のオブジェクトを更新します。
- 実用での使用場面: 特定の行ラベルと列名が分かっているセルをピンポイントで扱います。
- 使用例:

```python
df = sales.copy()
value = df.at[0, "store"]
df.at[0, "store"] = "Tokyo-main"
```

- よくある注意点:
  - `at[]` は単一セル専用です。複数行・複数列の抽出には `loc[]` を使います。
  - 行ラベルが存在しない状態で代入すると、新しい行が作られることがあります。タイプミスに注意します。
  - 整数インデックスでは、整数は位置ではなくラベルとして扱われます。
  - 1セル操作は明確ですが、大量更新は条件付きのベクトル化処理の方が高速で読みやすいことが多いです。
- 関連メソッド: `loc[]`, `iat[]`, `set_index()`, `copy()`
- インパクト: 1セル操作の意図が明確になります。大量の行ループで使うより、可能ならベクトル化処理を優先します。

## `iat[]`

- 基本の説明: 行番号・列番号で単一セルを高速に取得・更新します。
- 基本構文: `df.iat[行番号, 列番号]` / `series.iat[位置]`
- 主な引数/指定:
  - 行番号: 0始まりの整数位置を指定します。
  - 列番号: 0始まりの整数位置を指定します。
  - 代入: `df.iat[行番号, 列番号] = 値` の形で単一セルを更新できます。
- 戻り値: 単一セルのスカラー値を返します。代入時は元のオブジェクトを更新します。
- 実用での使用場面: 位置が決まっている表のセルを取り出すときに使います。
- 使用例:

```python
first_value = sales.iat[0, 0]
df = sales.copy()
df.iat[0, 0] = "Tokyo-main"
```

- よくある注意点:
  - `iat[]` は単一セル専用です。範囲指定や複数列指定はできません。
  - 列順・行順に強く依存します。読み込み条件や前処理で順序が変わると、別のセルを指す可能性があります。
  - 範囲外の位置を指定するとエラーになります。
  - 業務上の意味がある列や行を扱う場合は、`at[]` や `loc[]` の方が安全です。
- 関連メソッド: `iloc[]`, `at[]`, `loc[]`
- インパクト: 単一セルの位置指定が簡潔です。ただし列順依存なので、業務ロジックでは慎重に使います。

## `filter()`

- 基本の説明: 列名や行名を条件にして抽出します。値の条件抽出ではなく、ラベル名ベースの抽出です。
- 基本構文: `df.filter(items=None, like=None, regex=None, axis=None)`
- 主な引数/指定:
  - `items`: 抽出したいラベル名をリストで指定します。
  - `like`: 指定文字列を含むラベルを抽出します。
  - `regex`: 正規表現に一致するラベルを抽出します。
  - `axis`: `0` または `"index"` で行ラベル、`1` または `"columns"` で列ラベルを対象にします。`DataFrame` では省略時は列が対象です。
- 戻り値: 抽出後の `DataFrame` または `Series` を返します。
- 実用での使用場面: `sales_` で始まる列、特定キーワードを含む列だけを取り出すときに使います。
- 使用例:

```python
numeric_like = sales.filter(items=["quantity", "price"])
date_columns = sales.filter(regex="date")
sales_columns = sales.filter(regex="^sales_", axis="columns")
```

- よくある注意点:
  - `items`、`like`、`regex` は同時に使えません。目的に応じて1つだけ指定します。
  - 値の条件抽出ではありません。行の値で絞り込みたい場合は `loc[]` や `query()` を使います。
  - `items` に存在しない列を指定してもエラーにはならず、存在する列だけが返ります。必須列チェックには `columns` を使います。
  - 正規表現では意図せず広く一致することがあります。`^` や `$` で開始・終了を明示すると安全です。
- 関連メソッド: `loc[]`, `columns`, `select_dtypes()`, `query()`, `reindex()`
- インパクト: 列数が多いデータで、命名規則に沿って必要列を選びやすくなります。値で絞り込む場合は `loc[]` を使います。
