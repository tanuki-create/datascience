# ガウス過程と機械学習: 初学者向けノート

このノートは、書籍ページのスクリーンショットやOCRから作成したものではありません。ガウス過程と機械学習の一般的な考え方を、初学者が全体像をつかめるように整理した概念別ノートです。

## 1. ガウス過程とは何か

ガウス過程は、ひとことで言うと「ありそうな曲線の集まりを確率で扱う方法」です。専門的には「関数そのものに確率分布を置く方法」と説明されます。

普通の回帰では、観測データに合う1本の線や曲線を探す、と考えがちです。ガウス過程回帰では、1本の曲線だけを決めるのではなく、「ありえそうな曲線の集まり」を確率的に扱います。

たとえば、ある入力 `x` に対して出力 `y` を予測したいとします。

```text
x -> y
```

ガウス過程では、未知の関数 `f(x)` を次のように考えます。

```text
y = f(x) + ノイズ
```

ここで重要なのは、`f(x)` を固定された1つの式として決め打ちしないことです。点をいくつか観測すると、その点の近くでは曲線の候補が絞られ、観測点から離れた場所では候補の幅が広がります。ガウス過程は、この「もっともありそうな曲線」と「どれくらい不確かか」を同時に扱います。

ガウス過程はよく次のように書かれます。

```text
f(x) ~ GP(m(x), k(x, x'))
```

- `m(x)`: 平均関数。事前にどんな値を中心に考えるかを表す。
- `k(x, x')`: カーネル関数。2つの入力 `x` と `x'` がどれくらい似ているかを表す。

初学者の段階では、`m(x)` は多くの場合 `0` と置かれ、主役は `k(x, x')` だと考えると理解しやすいです。

ただし、平均関数が常にゼロでなければならないわけではありません。教材や実装例では簡単のためにゼロ平均を使うことが多い、というだけです。ゼロ平均から始めても、観測データを反映したあとの予測平均はゼロとは限りません。

## 2. 確率分布・正規分布・多変量正規分布の前提

ガウス過程を理解するには、まず「値を1つに決める」のではなく「値の候補を確率で表す」という発想が必要です。

### 確率分布

確率分布は、ある値がどれくらい起こりやすいかを表すものです。

たとえば、明日の気温を「25度」と1点で言うのではなく、「24度から26度あたりがありえそう。20度や30度は少し起こりにくい」と考えるのが確率分布の発想です。

### 正規分布

正規分布は、平均の近くが起こりやすく、平均から離れるほど起こりにくくなる分布です。

```text
N(平均, 分散)
```

- 平均: どの値を中心に考えるか
- 分散: どれくらいばらつくか

分散が小さいほど予測に自信があり、分散が大きいほど予測の不確かさが大きいと考えられます。

### 多変量正規分布

多変量正規分布は、複数の値をまとめて正規分布で扱うものです。

ガウス過程では、複数の入力点での関数値をまとめて考えます。

```text
[f(x1), f(x2), f(x3), ...]
```

この値の並びが多変量正規分布に従う、と考えるのがガウス過程の基本です。より正確には、「任意の有限個の入力点を選んだとき、その関数値の組が多変量正規分布に従う確率過程」がガウス過程です。

ポイントは、各点の値がバラバラに決まるのではなく、「近い入力同士なら似た出力になりやすい」という関係も同時に扱うことです。この関係を表すのが共分散であり、実際にはカーネル関数から作られます。

## 3. カーネル関数の直感

カーネル関数は、2つの入力がどれくらい似ているかを数値化する関数です。

ガウス過程では、カーネル関数が「どんな関数をありえそうだと考えるか」を決めます。つまり、カーネルはガウス過程の性格を決める部品です。

注意点として、カーネルは任意の「似ている度合い」なら何でもよいわけではありません。共分散行列として使えるように、正定値性という条件を満たす必要があります。初学者の段階では、まず実績のある標準的なカーネルを使うのが安全です。

### RBFカーネル

もっともよく使われるカーネルの1つがRBFカーネルです。

```text
k(x, x') = σ_f^2 exp(-||x - x'||^2 / (2l^2))
```

ここで重要なのは、式を暗記することではありません。直感は次の通りです。

- `x` と `x'` が近いほど、`f(x)` と `f(x')` は似ていると考える。
- `x` と `x'` が遠いほど、関係は弱くなる。
- `l` はどれくらい離れても似ていると見るかを決める。
- `σ_f^2` は関数全体の縦方向の変動の大きさを決める。

`l` は長さ尺度と呼ばれます。`l` が大きいと、なめらかでゆっくり変化する関数を想定します。`l` が小さいと、細かく変化する関数も許します。

### カーネルの選び方

カーネルは、データに対する仮定です。

- なめらかな関数を想定するなら `RBF`
- 少し荒い変化も許すなら `Matern`
- 周期性があるなら `Periodic`
- 直線的な関係を想定するなら `Linear`

初学者は、まずRBFカーネルでガウス過程の動きを理解し、そのあとデータの性質に応じて別のカーネルを見ると学びやすいです。

## 4. ガウス過程回帰の流れ

ガウス過程回帰は、観測データを使って未知の関数を予測する方法です。

観測データを次のように置きます。

```text
入力: X = [x1, x2, ..., xn]
出力: y = [y1, y2, ..., yn]
```

新しい入力 `x_*` に対して、出力 `y_*` を予測したいとします。

大まかな流れは次の通りです。

1. 平均関数とカーネル関数を決める。
2. 入力同士の似ている度合いから共分散行列 `K` を作る。
3. 観測ノイズを考慮して `K + σ_n^2 I` を作る。
4. 新しい入力 `x_*` と既存データの関係を計算する。
5. 予測平均と予測分散を求める。

ノイズを含む観測モデルは、よく次のように書かれます。

```text
y = f(x) + ε
ε ~ N(0, σ_n^2)
```

`σ_n^2` は観測ノイズの大きさです。測定誤差が大きいデータでは、この値を大きめに考える必要があります。

## 5. 予測平均と予測分散の意味

ガウス過程回帰の出力は、単なる予測値だけではありません。

```text
予測平均: もっともありえそうな値
予測分散: その予測の不確かさ
```

新しい入力 `x_*` での予測は、概念的には次のようになります。

```text
f(x_*) | データ ~ N(予測平均, 予測分散)
```

代表的な式は次の通りです。

```text
μ_* = k_*^T (K + σ_n^2 I)^(-1) y

σ_*^2 = k(x_*, x_*) - k_*^T (K + σ_n^2 I)^(-1) k_*
```

記号の意味は次の通りです。

- `K`: 学習データ同士のカーネル値を並べた行列
- `k_*`: 学習データと新しい入力 `x_*` のカーネル値を並べたベクトル
- `σ_n^2`: 観測ノイズの分散
- `I`: 単位行列

式を見ると難しく感じますが、直感は単純です。

- 近くに観測データがある場所では、予測分散は小さくなりやすい。
- 観測データから遠い場所では、予測分散は大きくなりやすい。
- 似ている入力の観測値ほど、予測平均に強く影響する。

この「予測値だけでなく不確かさも出せる」点が、ガウス過程の大きな利点です。

ただし、予測分散は単純な距離だけで決まるわけではありません。カーネルの種類、長さ尺度、ノイズ分散などの仮定にも依存します。

## 6. ハイパーパラメータと周辺尤度

ガウス過程では、カーネルの中にいくつかの調整値があります。これらをハイパーパラメータと呼びます。

RBFカーネルなら、代表的なハイパーパラメータは次の通りです。

- 長さ尺度 `l`
- 信号分散 `σ_f^2`
- ノイズ分散 `σ_n^2`

これらの値によって、予測結果は大きく変わります。

### 長さ尺度

長さ尺度 `l` が大きいと、関数はゆっくり変化すると考えます。予測曲線はなめらかになります。

長さ尺度 `l` が小さいと、関数は細かく変化してよいと考えます。予測曲線は観測点により敏感になります。

### 周辺尤度

周辺尤度は、ざっくり言うと「このハイパーパラメータのもとで、観測データがどれくらい自然に見えるか」を表す量です。

ガウス過程では、周辺尤度を最大化することでハイパーパラメータを調整することがよくあります。

```text
log p(y | X) =
-1/2 y^T (K + σ_n^2 I)^(-1) y
-1/2 log |K + σ_n^2 I|
-n/2 log(2π)
```

この式には、大きく3つの意味があります。

- データにどれくらい合っているか
- モデルが複雑すぎないか
- 正規分布としての正規化

初学者は、最初から式を完全に追う必要はありません。まずは「データへの当てはまり」と「複雑すぎるモデルへのペナルティ」を同時に見ている、と理解すると十分です。

入力特徴量のスケールにも注意が必要です。特徴量の単位や大きさがばらばらだと、長さ尺度の解釈や最適化が不安定になることがあります。そのため、標準化や正規化を先に行うことがよくあります。

## 7. 機械学習での使いどころ

ガウス過程は、特に次のような場面で役立ちます。

### データ数が少ない回帰

深層学習は大量のデータで強くなりやすいですが、データが少ないと扱いが難しいことがあります。ガウス過程は、少量データでも予測と不確かさを扱えるため、小規模な実験データや測定データに向いています。

### 不確かさが重要な予測

たとえば、単に「次の値は10です」と言うだけでなく、「10くらいだが不確かさは大きい」と分かることが重要な場面があります。

ガウス過程では、予測平均と予測分散が得られるため、判断に不確かさを組み込めます。

### ベイズ最適化

ベイズ最適化では、実験や評価に時間がかかる関数を効率よく最適化します。

たとえば、機械学習モデルのハイパーパラメータ探索では、1回の学習に時間がかかることがあります。ガウス過程で「どこを試すと良さそうか」と「どこがまだ不確かか」を推定し、次に試す候補を選びます。

### 注意点

ガウス過程は、標準的な実装ではデータ数 `n` に対して計算量が大きくなりやすいです。典型的には、行列計算のために `O(n^3)` 程度の計算が必要になります。

メモリも `O(n^2)` 程度必要になりやすいため、非常に大きなデータセットでは、近似手法や別のモデルを検討することがあります。

分類に使いたい場合も注意が必要です。ここで説明している標準的なガウス過程回帰は、出力が連続値で、ノイズが正規分布に従うことを前提にしています。分類では尤度が非ガウスになるため、ラプラス近似や変分推論など別の工夫が必要になります。

## 8. 初学者がつまずきやすい点

### 「関数の分布」という考え方が分かりにくい

最初は、関数を1本の線として考えたくなります。しかしガウス過程では、データを見る前には多くの関数候補があり、データを見たあとに候補が絞られる、と考えます。

1本の曲線ではなく、曲線の候補全体に確率を置いていると考えると理解しやすくなります。

### カーネルがただのテクニックに見える

カーネルは単なる計算上の部品ではありません。カーネルは「どの入力同士を似ていると見るか」「どんな形の関数を自然だと見るか」を決めます。

モデルの仮定そのものだと考えると、重要性が分かりやすくなります。

### 分散の意味を誤解しやすい

予測分散が小さいことは、必ずしも予測が正しいことを意味しません。モデルの仮定の中で自信がある、という意味です。

カーネルの選び方やノイズの仮定が現実とずれていると、自信のある間違いをすることもあります。

### ハイパーパラメータ最適化を万能だと思いやすい

周辺尤度を最大化しても、常に最良のモデルになるとは限りません。データが少ない場合や外れ値がある場合、局所解に入る場合があります。

実務では、可視化・複数初期値での最適化・データの前処理・カーネル選択をあわせて確認することが重要です。

また、標準化や正規化をせずに入力特徴量のスケールが大きくずれていると、カーネルの長さ尺度が解釈しにくくなります。ガウス過程を使う前に、入力の単位やスケールを確認する習慣を持つと安全です。

## 9. 最小限のPython実装イメージ

以下は、scikit-learnを使った最小限のガウス過程回帰の例です。

```python
import numpy as np
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import ConstantKernel, RBF, WhiteKernel


# 学習データ
X = np.array([[0.0], [1.0], [2.0], [3.0], [4.0]])
y = np.array([0.0, 0.8, 0.9, 0.1, -0.8])

# カーネル:
# ConstantKernel は縦方向の変動の大きさ
# RBF は入力が近いほど出力も似るという仮定
# WhiteKernel は観測ノイズ
kernel = ConstantKernel(1.0) * RBF(length_scale=1.0) + WhiteKernel(noise_level=0.1)

model = GaussianProcessRegressor(
    kernel=kernel,
    normalize_y=True,
    n_restarts_optimizer=5,
    random_state=0,
)

model.fit(X, y)

# 予測したい点
X_test = np.linspace(-1.0, 5.0, 100).reshape(-1, 1)

# return_std=True にすると、予測平均と標準偏差が返る
y_mean, y_std = model.predict(X_test, return_std=True)

print(model.kernel_)
print(y_mean[:5])
print(y_std[:5])
```

このコードで見るべき点は、予測値 `y_mean` だけではありません。`y_std` が予測の不確かさを表します。

観測点の近くでは `y_std` が小さくなりやすく、観測点から離れると大きくなりやすいです。これがガウス過程回帰の特徴です。

## 10. 学習の進め方

初学者は、次の順番で学ぶと理解しやすいです。

1. 正規分布と分散の意味を確認する。
2. 多変量正規分布で「複数の値が関係しながら分布する」感覚をつかむ。
3. カーネル関数を「似ている入力同士を結びつけるルール」として理解する。
4. ガウス過程回帰を、予測平均と予測分散を出す回帰として動かしてみる。
5. カーネルやハイパーパラメータを変え、予測曲線と不確かさがどう変わるかを見る。

最初の目標は、式をすべて導出できることではありません。まずは、次の3点を説明できるようになることを目標にするとよいです。

- ガウス過程は、関数に対する確率分布である。
- カーネルは、入力同士の似ている度合いと関数の形の仮定を決める。
- ガウス過程回帰は、予測値だけでなく不確かさも返す。

この3点が分かると、ガウス過程を機械学習の中でどう使うのかが見えやすくなります。
