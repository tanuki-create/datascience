最大部分配列

カデイン法（Kadane's algorithm）は、現在のインデックスで終わる最良の和だけを残す手法です。 不利な候補を捨てながら左から右へ1回走査するだけで、最良の連続区間を求められます。

知っておきたい用語

連続
要素のインデックスが途中で飛ばず、隣り合って並んでいることです。
部分配列
元の配列から取り出した、空でない連続区間です。
線形走査
入力を左から右へ一度だけ順番に調べる処理です。
動的計画法
すでに求めた小さな問題の答えを使って、より大きな問題の答えを組み立てる方法です。
分割統治法
問題を小さく分け、それぞれを解き、その答えを結合する方法です。

問題の要点

入力 1個以上の整数を含む配列 nums。
出力 空でない連続部分配列の和として得られる最大値。

カデイン法の9ステップ走査

各インデックスで、「この値から始める」場合と「直前までの最良の和を延長する」場合を比べ、大きい方を選びます。

    −2

    −2

    −2

    この値から始める

    x = −2

    選択

    直前の部分配列を延長する

    previous current_sum + x = 対象外

    ここから走査を開始
    判断 最初の値で両方の和を初期化します。
    最終的な最適部分配列：インデックス 3〜6

    [4, −1, 2, 1] の和は 4 − 1 + 2 + 1 = 6 です。二重下線のセルが、最適な連続区間を示します。

    ステップ 1 / 9。インデックス 0、値 −2。最初の値で両方の和を初期化します。

    アルゴリズムと正しさ

    擬似コード

    current_sum = nums[0]
max_sum = nums[0]

先頭の次から、各数 x について:
    current_sum = max(
        x,
        current_sum + x
    )
    max_sum = max(max_sum, current_sum)

max_sum を返す

    なぜ正しいのか

    • current_sum は、現在のインデックスで必ず終わる部分配列のうち、最大の和です。
    • そのような部分配列は、現在の値から始めるか、直前のインデックスで終わる最良の部分配列を延長するかのどちらかです。この比較で両方の場合を網羅できます。
    • 小さい方の候補には、今後も大きい方と同じ値が加算されるため、捨てても逆転することはありません。
    • max_sum は、処理済みの各インデックスで得られた current_sum の最大値を保持します。したがって、最後のインデックスを処理した時点で答えになります。

    計算量と別解

    時間計算量：O(n)
    線形走査で n 個の値をそれぞれ1回ずつ調べます。
    追加領域：O(1)
    アルゴリズムが入力とは別に使うメモリです。配列の長さに関係なく、2つの和だけを保持します。

    分割統治法による別解では、左半分の最良部分配列、右半分の最良部分配列、中点をまたぐ最良部分配列を比較します。時間計算量は O(n log n) なので、この問題では1回の走査で済むカデイン法の方が効率的です。
