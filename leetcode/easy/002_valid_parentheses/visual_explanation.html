Valid Parentheses

See how a last-in, first-out stack verifies that every bracket closes in the correct order.

Problem recap

Given a string containing only (, ), {, }, [, and ], decide whether it is valid.

  • Every opening bracket must close with the same bracket type.
  • Bracket pairs must close in the correct nesting order.
  • Every closing bracket must have a corresponding opening bracket.

Terms to know

Stack
A structure that removes the most recently added item first.
LIFO
“Last in, first out”: the stack's removal rule.
Push
Add an item to the top of the stack.
Pop
Remove the item currently at the top.
Top
The next stack item that would be removed.
Nesting
Placing one bracket pair inside another, as in {[]}.

Why matching counts are not enough

Algorithm and reasoning

Pseudocode

create an empty stack
map each closing bracket to its opening bracket

for each character in the string:
    if it is an opening bracket:
        push it onto the stack
    otherwise:
        if the stack is empty, return false
        pop the top opening bracket
        if it does not match, return false

return true only if the stack is empty

Why it works

  • The stack contains exactly the opening brackets not yet closed.
  • The innermost opening bracket is on top, so it must close first.
  • A missing or different top cannot be repaired by later input.
  • An empty stack at the end means nothing remains unmatched.
