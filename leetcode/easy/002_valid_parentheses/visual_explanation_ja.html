初級・データ構造

有効な括弧列

最後に追加した要素を最初に取り出すデータ構造であるスタックを使い、すべての括弧が正しい順序で閉じるかを確認します。

問題の要点

(、)、{、}、[、]だけで構成された文字列が有効かを判定します。

  • すべての開き括弧を、同じ種類の閉じ括弧で閉じます。
  • 括弧の組は、内側の組から閉じる入れ子の順序を守ります。
  • すべての閉じ括弧に、対応する開き括弧が存在します。

知っておきたい用語

スタック
最後に追加した要素を最初に取り出すデータ構造です。
LIFO（後入れ先出し）
「最後に入れた要素を最初に出す」というスタックの規則です。
push（プッシュ）
スタックの最上部（top）に要素を追加する操作です。
pop（ポップ）
スタックの top にある要素を取り出す操作です。
top（トップ）
次に取り出される、スタックの最上部の要素です。
入れ子
{[]}のように、ある括弧の組を別の括弧の組の内側に置く構造です。

アルゴリズムと根拠

擬似コード

空の stack を作成する
各閉じ括弧に、対応する開き括弧を割り当てる

文字列の各文字について:
    文字が開き括弧なら:
        stack に push する
    それ以外なら:
        stack が空なら false を返す
        top の開き括弧を pop する
        閉じ括弧と一致しなければ false を返す

stack が空の場合だけ true を返す

正しく判定できる理由

  • スタックには、まだ閉じていない開き括弧だけが残ります。
  • 最も内側の開き括弧が top にあるため、その括弧から先に閉じる必要があります。
  • top が存在しない場合や種類が異なる場合は、後続の文字では順序を修復できません。
  • 入力をすべて処理した後にスタックが空なら、閉じていない括弧は残っていません。

計算量

時間計算量と追加領域
指標計算量意味
時間O(n)n個の文字を1回ずつ読み取ります。
追加領域O(n)入力とは別に使うメモリです。最悪の場合は、n個の開き括弧をすべて保存します。

時間計算量は、入力が増えたときに処理量がどう増えるかを表します。空間計算量は、追加で使うメモリ量がどう増えるかを表します。Big O 記法は、これらの増え方を表す記法です。O(n)は線形増加を表し、nが2倍になると処理量や使用メモリ量もおおむね2倍になります。
