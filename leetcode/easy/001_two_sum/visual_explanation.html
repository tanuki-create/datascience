Two Sum

Step through the canonical example and watch one pass turn a sum into a constant-time lookup.

Problem recap

Given an integer array nums and an integer target, return the indices of two different elements whose values add up to target. The same index cannot be used twice, and the input contains exactly one valid pair.

Terms to know

Complement
The value needed to reach the target: target - current value.
Hash map
A key-value data structure. Python's dict is a hash map and usually finds a key in constant time.
Index
A numbered array position. Python uses zero-based indexing, so the first element is at index 0.
Constant time
A lookup whose average amount of work does not grow with the input size, written O(1).

Algorithm and correctness

Pseudocode

create an empty hash map named seen

for each index and number in nums:
    complement = target - number

    if complement is in seen:
        return [seen[complement], index]

    store number -> index in seen

Why it works

Before each check, seen stores an earlier index for every distinct value already visited. One earlier index is enough, even when a value appears more than once.

  • If the complement is present, its stored index and the current index identify two different elements that add to the target.
  • If it is absent, storing the current value preserves it for later checks.
  • Checking before storing prevents the current element from being paired with itself while still supporting duplicate values.

Approach Time Extra space Meaning

Big O notation describes how work or extra memory grows with input size n. Here, O(n) is linear growth and O(1) extra space is constant growth.
