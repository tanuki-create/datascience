## 292. Nim Game — Easy

[LeetCode公式ページ](https://leetcode.com/problems/nim-game/)

### 問題の要点

1回のターンで1〜3個の石を取り、最後の石を取った人が勝つ。

両者が最適に動く場合に、先手が勝てるかを判定する。

### 解法

4の倍数の状態は負けで、それ以外は勝ち。

```python
class Solution:
    def canWinNim(self, n: int) -> bool:
        return n % 4 != 0
```

4個のとき、先手が1〜3個のどれを取っても、相手は残りの石をすべて取れる。

4の倍数でない場合は、最初に `n % 4` 個を取って、相手に4の倍数を渡せる。

相手が1個取れば自分は3個、相手が2個取れば自分は2個、相手が3個取れば自分は1個取ることで、2人の合計を常に4にできる。

計算量は、時間 `O(1)`、追加空間 `O(1)`。

### コードをコンピュータの処理に分解する

```python
n % 4
```

は、`n` を4で割った余りを計算する。

```python
n % 4 != 0
```

は、余りが0ではないかを判定し、`True` または `False` を作る。

```python
return n % 4 != 0
```

は、その真偽値を返す。

## 一個下のレイヤーから見るための共通視点

ゲーム問題では、現在の状態を次のように整理する。

- 今、誰の手番か。
- 残りの石や得点がいくつか。
- 現在の状態から選べる手が何か。
- その手を選んだ後、相手が最適に動いた場合にどうなるか。

「自分が勝てる手が1つでもあるか」と「相手のすべての手に対して勝てるか」を区別することが重要。

Nim Gameでは、4個の状態を相手に渡すことが相手の選択肢をすべて負けにつなげる構造になる。
